# Typical — ภาพ มิติ น้ำหนัก และหูยก / P05

วันที่บันทึก 2026-09-16 ตามคำสั่งผู้ใช้เพิ่มเติม ใช้กับ Typical ทุกครอบครัว A/B/C/D และชิ้นส่วนที่ใช้ในสินค้า I/L/U ทั้ง48แบบ รวมการย้อนปรับงานที่ทำแล้ว
P05 ในชื่อเอกสาร/ภาพนี้เป็น revision ของชุดตรวจ Typical ไม่ใช่การประกาศว่าผ่านขั้น P5 แบบแม่แบบแล้ว

## ข้อกำหนดทุก Typical

1. มี tag และ revision ระบุ LH/RH ช่องเปิด และความสัมพันธ์กับสินค้า/ชิ้นจริง แยก type ออกจาก instance
2. มีภาพ3Dจาก geometry เดียวกับ2D ระบุว่าเป็น wireframe หรือโมเดลผิว ห้ามใช้ภาพตกแต่งแทนหลักฐานตรวจมิติ
3. มี2D หน้าตัด รูปด้าน และแปลนตามที่จำเป็น พร้อมมิติรวม กว้าง/สูง/ยาวหล่อ ความหนาตั้งฉากผิว รัศมี/ศูนย์โค้ง ความลาด ขนาดและตำแหน่งช่องเปิด ระยะเนื้อคอนกรีตจากขอบ และ datum
4. ตรวจ chain dimensions และมิติประกอบ: กริดไม่ใช่ความยาวหล่อ ระบุ gap/clearance แยกกัน; ค่าเสนอไม่ใช่ค่าที่ผู้ใช้อนุมัติผลิต
5. แสดงปริมาตรสุทธิและน้ำหนักประมาณรายชิ้น พร้อมสูตร ความหนาแน่น แหล่ง/สถานะสมมติฐาน และรายการที่ไม่รวม
6. มีข้อมูลหูยกตาม [L01](LIFTING_CONCEPT_L01.md) แยกถอดแบบ/พลิกชิ้น/ติดตั้ง โซนเสนอไม่ใช่พิกัดเจาะหรือหล่อจริง
7. มิติ pocket/insert/รอยต่อรับแรง/ระยะรองรับ/tolerance/พิกัดหูยกที่ยังไม่ออกแบบต้องระบุรอกำหนด ไม่ใส่ศูนย์และไม่ผ่าน completeness สำหรับแบบผลิต
8. เปลี่ยนรูปทรง ความหนา ช่องเปิด หรือวัสดุ ต้องคำนวณน้ำหนักใหม่และตรวจภาพ/มิติ/CG/แผนยก/แบบแม่แบบ/Revit/STAAD ที่ได้รับผลกระทบ ห้ามถ่ายสถานะอนุมัติจาก revision เก่า

### ฐานคำนวณที่ตรวจย้อนกลับได้

ใช้ความหนาแน่นทดลองคอนกรีตปกติ 2,400 kg/m³ ไม่ใช่ค่าที่ผู้ผลิตรับรอง และไม่ใช้แทนคอนกรีตมวลเบาโดยอัตโนมัติ
มวล kg = ปริมาตรสุทธิ m³ × ความหนาแน่น kg/m³; คำว่า “น้ำหนัก” ในตารางหมายถึงมวล ไม่ใช่แรง kN

- ซีกทึบ: พื้นที่หน้าตัด = 150×2425 + 150×1090 + π/4×(400²−250²) mm² แล้วคูณความยาว1485mm และหาร10⁹ ได้m³ ใช้พื้นที่โค้งจริง ไม่ใช่รวมกล่องซ้ำบริเวณมุม
- ซีก W01: หักช่อง900×1200×150mm = 0.162m³
- พื้น: 2660×1485×175mm
- แผงปิดปลายทึบ: 2660×2325×150mm
- แผงประตู: หักช่อง1000×2100×150mm = 0.315m³

สูตรอ้างอิงเฉพาะเรขาคณิต TS-C P03/P04 นี้ ไม่ใช่สูตรทั่วไปสำหรับ A/B/D หรือ node
ไม่รวมเหล็กเสริม อุปกรณ์ฝัง เหล็กจุดต่อ วัสดุตกแต่ง กระจก และชิ้นเติมเหนือแผงปลาย ยังไม่หักปริมาตรเหล็กแทนที่คอนกรีตหรือ pocket ที่ยังไม่กำหนด
จึงไม่ใช่น้ำหนักชิ้นงานสำเร็จสำหรับเลือกเครน/หูยก และไม่รวมเผื่อแรงกระชาก แรงดูดแบบ มุมสลิง หรือความไม่เท่ากันของแรงแต่ละจุด
liftingDesignMassKg และ CG ที่ผ่านตรวจยังเป็น null; releasedForLifting=false

## การย้อนปรับและข้อคงค้าง

เก็บภาพ P02/P03/P04 เดิมเป็นประวัติ เพิ่มฉบับคำแนะนำโซนยก L01 ใน [ทะเบียน L01](../../output/lifting-concept-l01/register.json) ข้อความโซนไม่ใช่ตำแหน่ง anchor ที่ติดตั้งได้
ชุด P05 เพิ่ม3D/2D/มิติที่กำหนดแล้วและมวลทั้ง7 Typical เท่านั้น ยังไม่ครบ48สินค้า และมิติรายละเอียดผลิตยังไม่ครบ
เว็บ R02 ยังไม่ได้เชื่อมทะเบียนเหล่านี้; ขั้น P4 ต้องแสดงภาพ ตารางมวล สมมติฐาน สถานะมิติ/หูยก และดาวน์โหลด revision ที่ตรงกัน โดยรักษา ACL ภายในทีม
Revit ใช้ข้อมูลเดียวกันและ schedule ราย instance; STAAD ใน P7 ใช้น้ำหนักตามวัสดุ/geometry ที่ตรวจแล้ว ไม่ป้อนมวล kg เป็นแรงโดยตรง
งานนี้เป็น geometry/quantity check ไม่ใช่การวิเคราะห์โครงสร้างหรืออนุมัติความหนา เหล็ก จุดต่อ และการยก
