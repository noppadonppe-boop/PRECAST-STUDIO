# P75–P76 — บัญชีแรงปัจจุบันและคัดกรองผิวแม่แบบ

ขั้น5/8 ยังดำเนินการตามข้อกำหนดครบ8ด้านของ P40 ไม่ปิดขั้น5และไม่เริ่มขั้น6

## P75: น้ำหนัก / CG / แรงรายชุด

[รายงาน12รุ่น](../../output/abd-load-ledger-p75/index.html) รวม P66+P71+P74 ครั้งเดียว: ชิ้นค้ำ20และแผ่นรอยต่อ36ติด owner เดิม ส่วนฮาร์ดแวร์รอยต่อ72ชิ้นอยู่แยกและถอดตาม sequence จริง ไม่บวก P67/P69 ซ้ำ

- แม่แบบเหล็ก A/B/D รุ่นซ้ายขวาทึบ/หน้าต่าง: 5,652.008–5,686.252 kg ตามโมเดล ไม่รวม weld/seal/coating/rebar/rigging/อุปกรณ์ยังไม่สร้าง
- บัญชี159ชิ้นรุ่นทึบ/186ชิ้นรุ่นหน้าต่าง เป็นจำนวนชุดย่อยถอดและฮาร์ดแวร์ ไม่ใช่จำนวนแผ่นเหล็กทั้งหมดใน BOM ผลิต
- อัปเดต CG ราย owner/ทั้งชุด/แต่ละสถานะถอด จนเหลือฐาน M00 ไม่ถือว่าสถานะเหล่านี้มีระบบรองรับที่ผ่านกำลังแล้ว
- ผิวแรงดัน W01/W02 เดิมถ่ายไปชุด WC ปัจจุบันอย่างชัดเจน; ไม่เอาแรงกระทำ WC ไปอ้างเป็นแรงพุกรายตัว
- แยกกรณีมวลจริง concrete2400kg/m³ จากกรณีแรงดัน gamma25kN/m³+น้ำหนักเหล็ก ไม่บวกน้ำหนักคอนกรีตซ้ำกับแรงดันฐาน
- ตรวจสมดุลรวมและโมเมนต์/แรงสะท้อน LH↔RH ผ่าน18tests ยังไม่แก้สมการ compatibility หาปฏิกิริยารอยต่อหรือฐาน

P70 มวลเดิมและ P71 มวลก่อนล็อกรอยต่อเป็นประวัติ ใช้ P75 สำหรับรูปทรงชุดปัจจุบันเท่านั้น การเพิ่มชิ้นส่วนใหม่ทำให้ P75 ต้องปรับอีก

## P76: การคัดกรองผิวเหล็ก ไม่ใช่ผล plate/shell analysis

[ตารางเปรียบเทียบ](../../output/abd-skin-screen-p76/index.html) ใช้แรงดันฐาน37.125kPa, E200000MPa, nominal fy235MPa ตามฐานศึกษาP40 และผิว6mmเทียบ8/10mm ไม่มีการเลือกความหนาใหม่หรือแก้geometryคอนกรีต

แถบ1mm ช่วงซี่โครงแบบ simple span ใช้ระยะศูนย์กลางซี่; ปลายใช้ cantilever จากหน้าซี่สุดท้ายโดยไม่ให้เครดิตรอยต่อ/แบบข้าง เป็นแบบจำลองเฉพาะที่เพื่อชี้บริเวณต้องตรวจ มิใช่โมเดลรองรับร่วมจริง พิกัดซี่มาจาก P66 และการสะท้อนใช้ระบบพิกัด fabrication ของ LH อย่างถูกต้อง

ตัวอย่าง A-LH-S00: ปลาย M01=300mm, M02≈394.508mm, M03≈477.029mm ให้ elastic stress ของผิว6mm≈278.44/481.50/704.00MPa ในกรณีไม่ให้เครดิตรอยต่อ จึงต้องพัฒนาระบบรองรับขอบ/รอยต่อก่อนปิดขนาดผิว ไม่แปลว่าโครงทั้งชุดวิบัติจริง และไม่ถือค่าการโก่งหลังเกินครากเป็นค่าทางกายภาพที่เชื่อถือได้

ช่วง simple300mm ผิว6mmให้ stress69.609MPa/deflection1.08765mm; ไม่ใช่ code PASS และยังไม่มีเกณฑ์การโก่งสำหรับอนุมัติผลิต ผล B หลังคาเป็นการแทนผิวโค้งด้วยแถบราบ ไม่รับรองเป็น upper bound

ยังไม่ครอบคลุมแถบระดับช่องเปิด/ซี่ขาดตอน, รอยเชื่อม/ความยืดหยุ่นซี่, plate action, partial fill, impact/vibration, ระบบฐานและเสถียรภาพ ตรวจสมการมาตรฐานพื้นฐานกับ hand benchmark และ mirror รวม20tests

## ความคืบหน้าที่รายงานได้

งานย่อยบัญชีแรง/มวล12/12=100%; งานย่อย screening12/12=100% ไม่ใช่ขั้น5ครบ100%. ไม่มีฐานคำนวณเปอร์เซ็นต์รวม P40 ที่ตรวจเสร็จ จึงไม่อ้าง50%เดิมหรือใช้จำนวนภาพแทนเปอร์เซ็นต์วิศวกรรม

ขั้นถัดไปในขั้น5: จัดแบบจำลองรองรับร่วมผิว–ซี่–waler–ค้ำ–seam/base locks เพื่อตรวจแรงจุดต่อ/ความแข็งแรงและตัดสินใจเพิ่มซี่ขอบหรือผิว แล้วประสานทางถอดใหม่ รวมระบบรองรับ/ยก/พลิก งานเชื่อม/เกลียว/tolerance/seal และแบบผลิต/QCครบ44setupตามP40

P52 คงเดิม: แนวเหล็กคอนกรีตไม่ระบุขนาด สมมติ concrete lifting capacity เพียงพอเฉพาะการพัฒนา ไม่ยืนยันกำลังจริงของพุกหรือระบบยก เว็บปัจจุบันยังP68 รายงานนี้แยกไฟล์ไม่เปลี่ยนรูปเดิม
