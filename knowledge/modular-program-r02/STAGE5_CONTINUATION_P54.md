# P54 — ปิดช่องว่างแบบพื้นเว้าสองด้าน

ต่อจากP53โดยคงเงื่อนไขยกคอนกรีตP52 และขอบเขตแม่แบบP40 ไม่เริ่มขั้น6

เพิ่มโมเดลhardwareแม่แบบพื้นNF01 N01/N02: ฐาน1+ข้าง6, stock73และhardware47ชิ้นต่อชุด รวมพินกันหมุน2ชิ้นสำหรับแบบสั้น มีบัญชีชิ้น/รู/มวล/CG/3D/แปลน/ลำดับถอด และผลแรงจากพื้นที่เว้าจริง

หลักฐาน: [ชุดแบบ](../../output/notched-mould-p54/README.md), [รายการแรง](../../output/notched-demand-p54/README.md), generator `notched-mould-p54.mjs` และ `notched-demand-p54.mjs` ใน tools/modular-program

พบการชนจริงเมื่อดึงM02ตรง300mm จึงใช้ถอย20แล้วขึ้น250mmก่อนถอดM03 ตรวจ SAT ต่อเนื่อง54ช่วงและพื้นที่ประแจ15จุดต่อชุด ไม่ใช่แค่ภาพต้น/ปลาย. ผลนี้ยังไม่รวมเครน พื้นที่พัก tolerance หรือแรงขณะปลด

แรงซี่โครงใช้ shape-function integration ของพื้นที่คอนกรีตสองสี่เหลี่ยม ไม่แบ่งน้ำหนักให้4ฐานเท่ากันและไม่ใช้bboxเต็ม. มี4กรณี N01/N02 × static/surcharge2.5kPa กรณีสมมติ; ตรวจแรงและfirst momentsรวมทั้งสะท้อนแรงฐาน. ไม่อ้างcode capacityจากelastic analysis
