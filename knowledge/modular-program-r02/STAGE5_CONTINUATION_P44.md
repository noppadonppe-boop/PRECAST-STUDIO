# P44 — ต่อขั้น 5 ตามคำสั่งให้ครบ 100%

คำสั่งล่าสุดอนุญาตให้ทำขั้น 5 ต่อ ไม่เริ่มขั้น 6 และไม่เปลี่ยนเกณฑ์การรับรองผลิต

ฐานแรงดันเทครบ44 setup: `output/mould-demand-p44/demand-register.json` พร้อม CSV และรายงาน README สร้างจากความสูงพิกัดท่าหล่อจริง ตรวจตรงทะเบียนทุกชิ้น ไม่ใช้ความสูงติดตั้ง3เมตร

แรงดันเป็นกรณีศึกษาของไหลสถิต gamma25 kN/m³ เทจากบน ตามฐานเดิม P40 แยกแรงดันสามเหลี่ยมจาก uniform screening ของ P41 เป็นคนละ load case ไม่ใช่การออกแบบรับแรงครบหรือผลแรงเฉพาะโบลต์

สถานะตรวจ: ภาพนำเสนอ44/44; hardware solidsมีเฉพาะpilot1/44; full strength/lifting/factory support checksยังไม่ครบทั้ง44 ไม่เปลี่ยน overall50%ด้วยการสร้างรายการข้อมูลหรือภาพ

งานที่ต้องดำเนินต่อ: โมเดลอุปกรณ์43setup, คำนวณทั้งระบบ, แบบรายละเอียด, ตรวจเส้นทางถอดและการเข้าถึง, ระบบยกและการตรวจรับ ข้อมูลพื้นโรงงาน/กำลังวันยก/เหล็กจริง/ผลิตภัณฑ์พุกยังขาด จึงยังปิดรายการที่อาศัยข้อมูลเหล่านี้ไม่ได้ งานที่ขาดทั้งแบบและการคำนวณไม่ใช่เพียงรอผู้ใช้อนุมัติ

ยังรักษาคำสั่งเสนอรูปทรงเหล็กเสริมโดยไม่ระบุขนาด ไม่ถือว่าการขอ100%ยกเลิกข้อจำกัดนี้
