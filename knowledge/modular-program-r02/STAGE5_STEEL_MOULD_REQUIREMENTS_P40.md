# P40 — ออกแบบแม่แบบเหล็กพร้อมกลไกและระบบยก

วันที่ 2026-09-17 — ข้อกำหนดผู้ใช้ล่าสุด แทนขอบเขตที่เลื่อนงาน hardware/ความแข็งแรงแม่แบบไปอนาคตใน P39

## คำสั่งและขอบเขตที่ยืนยัน

ให้ออกแบบแม่แบบเหล็กสำหรับ Segment จริง รวมจุดล็อก ค้ำยัน ความแข็งแรงแม่แบบ และระบบยกในขั้น 5 ไม่ใช่เพียงภาพช่องหล่อหรือป้ายว่า “รอออกแบบ” งานวิศวกรรมแม่แบบและการจัดการชิ้นงานได้รับอนุญาตในขั้นนี้ แยกจากการวิเคราะห์อาคารทั้งหลังด้วย STAAD ในขั้น 7 ซึ่งยังไม่เริ่ม

เริ่มพัฒนาตัวอย่าง TS-C-H15-LH-W01 ต่อจาก P39 ให้ผู้ใช้ตรวจ ก่อนแทนที่งานเดิมหรือขยาย Typical ที่เหลือ ไม่เปลี่ยนภาพชุดเดิมในเว็บไซต์เอง

ภาพแนบ 04-shape-library, 02-precast-modular, 03-curved-edges และ 05-modular-options ใช้สื่อรูปแบบการนำเสนอและหลักการแบ่งชิ้น ไม่ใช่หลักฐานขนาด กำลัง หรือกลไกของโครงการ ห้ามคัดลอกโมลห้องเต็มมาแทน Segment ซีกผนัง–หลังคาของเรา

## ผลส่งมอบที่ต้องมีต่อ Segment

1. บัญชีแม่แบบ แยกชุดย่อยกับชิ้นผลิตจริง ฐาน/แบบนอก/แบบใน/หัวท้าย/บล็อกช่องเปิด พร้อม Tag และจำนวน รวม hardware, pin, lock, brace และ lifting attachments โดยไม่แอบรวมเป็น 13 ชุดเดิม
2. ภาพ 3D รายชิ้นและมิติสัมพันธ์กับ Typical: หน่วย พิกัด รัศมี ความหนา ช่องเปิด tolerance และ revision ต้นทาง
3. ภาพระเบิดและประกอบครบ เห็นช่องคอนกรีต จุดล็อก ค้ำ รอยต่อ ซีล พื้นที่เครื่องมือ รวมช่องทางเทและเครื่องจี้ตามวิธีที่เลือก
4. ลำดับประกอบ/ถอด ระบุการรองรับในแต่ละช่วง ปลด lock/brace เมื่อใด และตรวจเส้นทางเคลื่อนต่อเนื่องรวม hardware ไม่ใช่แค่ต้นทางและปลายทาง
5. ภาพชิ้นคอนกรีตหลังถอดจาก geometry เดียวกับ Typical ไม่เปลี่ยนรูปทรงเพื่อให้ภาพดูสวย
6. รายการคำนวณแม่แบบ: แรงดันคอนกรีตสด, ผิวเหล็ก/ซี่โครง/โครงหลัก/ฐาน, การโก่ง, weld/bolt/pin/lock, brace/anchor, การเลื่อน/คว่ำ และเสถียรภาพช่วงประกอบ/ถอด
7. ระบบยกแยกแม่แบบเปล่า ชิ้นแบบที่ถอด คอนกรีตหลังถอด และการพลิกชิ้น พร้อมน้ำหนักรวม CG จุดยก rigging แรงแต่ละขา และการตรวจชิ้นคอนกรีต/พุกในอายุยก ไม่ใช้ค่า fc28 แทนกำลังยก
8. แบบรายละเอียดผลิตและตรวจคุณภาพ อ้าง calculation/model revision เดียวกัน; ระบุการตรวจทดลองประกอบและการทดสอบที่ต้องทำก่อนใช้งานจริง

## วิธีทำงาน — ไม่ใช้คำเตือนแทนงานออกแบบ

เลือกและเสนอขนาดวัสดุ/รายละเอียดได้ภายในงานออกแบบนี้ พร้อมคำนวณและแสดงสมมติฐาน การมีขนาด Segment ไม่เพียงพอที่จะรับรอง load capacity เอง ข้อมูลที่ยังไม่ทราบต้องอยู่ในทะเบียน input และติดตามผลกระทบ ไม่ใส่ค่าศูนย์หรือประกาศว่าผ่านแล้ว

เมื่อพบสิ่งที่ยังไม่ออกแบบ ให้บันทึกเป็นงานที่ต้องปิดในขั้น 5 ไม่ใช้เป็นเหตุผลตัดออกจาก deliverable; ถ้าข้อมูลโรงงานยังไม่มาให้ทำกรณีศึกษาและกำหนด operating envelope ที่ตรวจได้ แยกจากอนุมัติใช้งานจริง

ชุดคำนวณต้องแยก demand / simplified screening / code check / manufacturer check / human release ไม่รายงาน elastic beam check หรือ geometry PASS ว่าทั้งแม่แบบปลอดภัย

## คำตอบผู้ใช้ระหว่างทำงาน

- ข้อตกลงล่าสุด [P52](decision-lifting-p52.json): สมมติกำลังยกคอนกรีตเพียงพอเพื่อพัฒนาแบบ แสดงแนวเหล็กไม่ใส่ขนาด เดินหน้างานส่วนนี้โดยไม่รอผลเหล็กจริง ไม่ใช่การรับรองพุก/อุปกรณ์หรือการยกจริง; ข้อกำหนดแม่แบบส่วนอื่นคงเดิม

- เพิ่มเติมในP41: คงความหนา Segment ตามขั้น2; เสนอรูปทรงเหล็กเสริมก่อน ไม่ระบุขนาดเหล็ก ดู [P41](STAGE5_PILOT_P41.md) ไม่ถือว่าข้อความนี้เป็นข้อมูลพื้นโรงงานหรืออนุมัติยก

- ยืนยัน **เทจากด้านบน**
- ผู้ใช้ระบุ “ไม่จำกัดเครน ได้ทุกน้ำหนัก”: ไม่ใช้เครนที่มีอยู่เป็นข้อจำกัดตั้งต้น ให้หา required crane capacity จากน้ำหนัก/rigging/ระยะยก/ความสูงจริง ไม่ถือว่าเครนมี capacity อนันต์ ไม่ใช่การเลือกเครนหรืออนุมัติแผนยกแล้ว
- ยังไม่ได้ระบุให้ยกแม่แบบพร้อมคอนกรีต ใช้การยกแยกเป็นข้อเสนอเริ่มต้น

## ฐานศึกษาเริ่มต้น P40 (แยกค่าผู้ใช้ยืนยันจากสมมติฐาน)

- ใช้ geometry ของ P39 ตามต้นทาง ไม่เปลี่ยนมิติ Segment
- เทจากด้านบนตามผู้ใช้ยืนยัน ความสูงคอนกรีตสด 1.485 ม.; gamma 25 kN/m3 เป็นสมมติฐานออกแบบแรงดัน ไม่แก้ความหนาแน่น 2400 kg/m3 ที่ใช้รายงานมวลต้นทาง
- แรงดันสถิต p(z)=gamma*(H-z); ตรวจผิวแผ่นแบบง่ายด้วยแรงดันฐานกระจายสม่ำเสมอเต็มช่วงเป็น screening envelope เพิ่มเติม ไม่ครอบคลุม pump pressure/impact/vibration โดยอัตโนมัติ
- เหล็ก E=200000 MPa; เปรียบเทียบกับ nominal fy235 MPa เป็นสมมติฐาน ไม่ใช่การเลือกเกรดจากใบรับรอง และไม่ใช่ allowable stress ตาม code
- ไม่ยกแม่แบบพร้อมคอนกรีตในกรณีเริ่มต้น; ห้ามอนุมานพิกัดเครน หรือแบ่งน้ำหนักเท่ากันทุกหูยก
- วิธีเทยืนยันแล้ว; ต้องกำหนดเครน/ระยะยก/ความสูงเกี่ยวตะขอ วิธีพลิก กำลังคอนกรีตตอนยก พื้นโรงงาน และระบบพุกก่อนปิดรายละเอียดที่ขึ้นกับข้อมูลเหล่านี้
