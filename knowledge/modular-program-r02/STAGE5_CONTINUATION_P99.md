# P98 / P99 — ชุดแบบรวมปัจจุบัน 44 setup

ขั้น 5/8 ยังอยู่ระหว่างออกแบบตาม P40; ไม่เปลี่ยนขอบเขตเพื่อรายงาน100% และไม่เริ่มขั้น6

## ผลงานรอบนี้

- P98 ตรวจรูปทรงคอนกรีต44/44กับ P38 → instance ขั้น3 → Typical ต้นทาง รวมแปลงท่าหล่อครอบ9ชนิดกลับด้วย proper rotation. ตรวจทั้งขอบวนของface ไม่ใช่ดูboundingboxหรือvertexอย่างเดียว. ครบ100%เฉพาะ nominal geometry correspondence ไม่ใช่รับรองค่าคลาดเคลื่อนโรงงานหรือผิวแม่แบบครบ
- P99 รวมโมเดลแม่แบบ44ชุดจาก geometry ที่ทำแล้ว: C=P59, A/B/D=P85+P71+P74+P80อย่างละครั้ง, โต๊ะ=P97รวมP94/P95/P96, พื้นเว้า=P54, แผงปลาย=P58, ครอบ=P56. ไม่ยกทางเลือกP89เป็นรุ่นใช้งานและไม่สืบทอดcapacityของรุ่นเก่า
- มี44ภาพประกอบ/แยกประกอบ +44ภาพ3Dชุดย่อย,44บัญชีชุดย่อย/hardware,44ลำดับถอด,44โมเดลJSONและ44หน้าตรวจรวม. รูปทรงสร้างจากข้อมูลโมเดล ไม่ใช่สร้างภาพใหม่ด้วยAI. ภาพP43และแผนยกP52/P91เดิมเก็บไว้ให้เทียบ
- ภาพชิ้นย่อยรวมM/C/W: เพิ่มC01–C03ของแผงมีประตูซึ่งร่างแรกของภาพแยกประกอบตกหล่น. แผงทึบS01ไม่มีC01 ไม่สร้างชิ้นเกินต้นทาง
- ภาพแยกประกอบใช้ผลรวมเวกเตอร์ถอดของต้นทาง จึงอาจมีชิ้นบังกันในมุมภาพ; ใช้ภาพรายชิ้นประกอบ ไม่ถือภาพแยกเป็นการพิสูจน์ยกทุกชิ้นพร้อมกันหรือเส้นทางเครน

## การอ่านมิติ น้ำหนัก และจำนวน

`parts` เป็นชุดย่อย/hardware ไม่ใช่จำนวนชิ้นตัดผลิต. `dimensionsXYZmm` คือกรอบในแกนหล่อ ไม่ใช่cutting dimensions. `nominalStockMassKg` เป็นผลรวมsolid cellsของstockที่มี บางต้นทางมีเนื้อเหล็กซ้อนกันและบางอุปกรณ์ยังไม่ครบ ไม่ใช่มวลสำเร็จ/WLL. น้ำหนักคอนกรีตแยกค่าต้นทางกับfacetedmeshและไม่รวมเหล็ก/พุก. ค่า verified capacity ยังไม่ถูกสร้างขึ้นจากการรวมไฟล์

## เกณฑ์ปิดขั้น5ที่ยังไม่ครบ

P99ปิดได้เฉพาะ P40-5 เรื่องชิ้นคอนกรีตตรงTypicalสำหรับรุ่นที่ตรึงไว้นี้. P40-1/2/3/4/6/7/8 ยังมีงานออกแบบจริง ไม่ใช่เหลือเพียงผู้ใช้กดอนุมัติ:

1. บัญชีชิ้นตัด/รู/เกลียว/รอยเชื่อม/ซีลและอุปกรณ์รองรับต้องตรงกับโมเดลกำลังรุ่นเดียวกัน
2. ค่าคลาดเคลื่อน ช่องเครื่องมือ และช่องเท/จี้ต้องปิดตามอุปกรณ์ที่ใช้จริง
3. กำลังจุดต่อ/ฐาน/ค้ำและเสถียรภาพทุกช่วงยังไม่ครบทุกครอบครัว
4. จุดยกแม่แบบ อุปกรณ์พยุงระหว่างปลด ระบบพลิก และแรงลงพื้นต้องออกแบบและตรวจครบ; P52ยกเว้นเพียงกำลังคอนกรีตเพื่อพัฒนา
5. แบบผลิต/QCสุดท้ายต้องผูกกับผลตรวจดังกล่าวก่อนส่งให้ผู้รับผิดชอบตรวจอนุมัติ

ใช้ `output/stage5-library-p99/closure-register.json` เป็นรายการปัจจุบัน; P90คงเป็นประวัติ. `stageCompletionPercent=null` เนื่องจากยังไม่มีฐานแบ่งน้ำหนักงานที่ตรวจรับแล้ว ไม่ใช้44/44ภาพหรือ1/8หมวดเป็นเปอร์เซ็นต์ทั้งขั้น
