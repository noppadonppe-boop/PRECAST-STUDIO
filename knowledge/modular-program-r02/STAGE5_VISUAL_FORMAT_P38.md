# ข้อกำหนดเพิ่มจากผู้ใช้ — ภาพแม่แบบแบบตัวอย่าง

**ถูกแทนด้านวิธีสร้างภาพโดยคำสั่งผู้ใช้ล่าสุด:** ดู [P38-R1](STAGE5_REALITY_REVIEW_P38R1.md) ห้ามใช้ AI สร้างรายละเอียดแม่แบบขึ้นเอง ต้องฉายจาก geometry และแยกส่วนที่ยังไม่มีแบบ ข้อกำหนด imagegen ด้านล่างเป็นประวัติ ไม่ใช่วิธีส่งงานปัจจุบัน

อ้างอิงภาพที่ผู้ใช้ส่ง `Picture Stock/Form Work/Precast-Formwork-Concept-Package/formwork-concepts/01-precast-panel.png` เป็นแนวทางจัดหน้าและคุณภาพภาพ ไม่ใช้รูปแผงเรียบในตัวอย่างแทนgeometryของโครงการ

เพิ่มภาพนำเสนอ3Dแบบสมจริงรายsetup: ภาพแยกประกอบหลัก + ชิ้นสำเร็จ + callouts + รายละเอียดขยาย + ลำดับประกอบ/ถอด พื้นขาว หัวเรื่องกรมท่า โครงแบบสีน้ำเงิน
ใช้ built-in imagegen ตามSkill; ตรวจภาพก่อนรับเข้าworkspace ภาพAIเป็นconcept visualization ไม่ใช่หลักฐานมิติ ไม่แทน00Typical/01Cavity/02Tooling/JSONจากgeometryจริง
เหล็ก แคลมป์ ซี่โครงและฐานที่แสดงเป็นสัญลักษณ์เชิงแนวคิด ไม่เลือกขนาด/วัสดุ/กำลังให้ผลิต หูยกแสดงstudy zones ไม่ใส่พิกัดอนุมัติ
