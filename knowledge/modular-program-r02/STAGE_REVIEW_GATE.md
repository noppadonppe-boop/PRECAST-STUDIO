# กติกาจบขั้นและรอผู้ใช้ตรวจ — 17 กันยายน 2026

คำสั่งผู้ใช้: “ให้ดำเนินการ แต่ละขึ้นตอนให้ 100% แล้วค่อยหยุดให้ฉันตรวจสอบแล้วรอคำสั่งขึ้นตอนถัดไป”

ใช้กับขั้นหลัก1–8ตามR02 ไม่ใช่เลขrevision P20/P21 เป็นต้น

1. เมื่อได้รับคำสั่งให้ทำขั้นหนึ่ง ให้ทำงานภายในขั้นนั้นต่อเนื่องจนผ่านรายการตรวจรับครบ100% ไม่หยุดเพื่อขอคำสั่งต่อเพียงเพราะจบงานย่อยหรือภาพหนึ่งชุด
2. ระหว่างทำรายงานขั้นและเปอร์เซ็นต์ตามหลักฐานจริง ไม่เพิ่มเปอร์เซ็นต์เพียงเพื่อให้ครบตามคำสั่ง ไม่ลดเกณฑ์หรือย้ายงานที่ยังขาดไปขั้นอื่นโดยพลการ
3. เมื่อครบ100% ส่งชุดผลงาน ลิงก์ไฟล์ ผลตรวจ และข้อจำกัดที่ไม่ขัดกับเกณฑ์จบขั้น แล้วหยุดในสถานะAWAITING_USER_STAGE_REVIEW
4. ผู้ใช้ตรวจแล้วต้องมีคำสั่งเริ่มขั้นถัดไป จึงทำขั้นถัดไปได้ การครบ100% คำชม หรือการขอแก้ไขงานเดิมไม่ใช่อำนาจเริ่มขั้นถัดไป
5. หากผู้ใช้ขอแก้ ให้แก้ภายในขั้นเดิม ตรวจผลใหม่ และหยุดส่งตรวจอีกครั้ง หากข้อแก้กระทบเกณฑ์ที่เคยผ่าน ให้ทบทวนเปอร์เซ็นต์ตามจริง
6. ก่อนครบ100% หยุดเพื่อถามได้เมื่อจำเป็นต้องมีการตัดสินใจ/สิทธิ์/ข้อมูลจากผู้ใช้ที่ทำแทนไม่ได้ หรือไม่มีทางทำงานต่ออย่างปลอดภัย ไม่ใช้การรอคำตอบเป็นเหตุหยุดงานอิสระที่ยังทำได้
7. คำสั่งนี้ไม่เลือกวัสดุหรือรายละเอียดที่ยังไม่สรุป ไม่อนุมัติรับแรง/ผลิต และไม่อนุญาตข้ามขั้น7ไปตรวจโครงสร้างในขั้น2

สถานะขณะเพิ่มกติกา: ขั้น2/8 ที่80% (16/20) ยังไม่จบขั้น ยังไม่ส่งตรวจปิดขั้น2 และยังไม่ได้เริ่มขั้น3 การแก้กติกาการทำงานครั้งนี้ไม่เพิ่มเปอร์เซ็นต์งานแบบ
