## ขนาดและมวล

TS-N90-NR01-P14 กว้าง2985 × ยาว1485 × หนา175มม. ใช้2แผ่นต่อโหนด ไม่เพิ่มยอดNRเหนือP11 มี1Typicalใหม่ รวมแผ่นTypicalเสนอ33รายการ ไม่ใช่33แบบหล่ออนุมัติ

local min ของแผ่นที่1=(7.5,7.5,2675), แผ่นที่2=(7.5,1507.5,2675) อ้างมุมกริดโหนด กริดX=7.5+2985+7.5=3000; Y=7.5+1485+15+1485+7.5=3000

ปริมาตร2985×1485×175/10⁹=0.775726875m³ มวลที่ความหนาแน่นทดลอง2400kg/m³=1861.7445kg/แผ่น รวม3723.489kgต่อโหนดเฉพาะคอนกรีตหลังคา ไม่รวมเหล็ก อุปกรณ์ pockets งานทำลาด ฉนวน กันน้ำ และระบบรองรับ wholeNodeMassKgยังnull

## ระดับและระบบรองรับ

บนNR2850 ใต้2675 เหนือพื้น175เหลือ2500ก่อนตกแต่ง; บนผนังNW2655มีพื้นที่ประสาน20 ไม่ใช่รายละเอียดbearingหรือการอนุมัติให้เท groutรับแรง การทับกันในแปลนไม่ให้เครดิตระยะรองรับ จึงยังไม่ระบุช่วงพาดเชิงโครงสร้างหรือความสามารถรับแรง หน้าด้านเปิดและรอยต่อกลางต้องประสานกรอบรองรับ/ระบบรับแรงภายหลัง

แผ่นระดับเป็นเพียง geometryศึกษา drainageSlope=null ไม่ใช่สรุปว่าหลังคาไม่ต้องทำลาด ช่องระบายน้ำ/overflow/ชั้นกันน้ำ/ฉนวน/รายละเอียดปิดpocketยังไม่เลือก เมื่อกำหนดต้องทบทวนมวล ระดับยอดและความสูงเป้าหมาย3ม.ร่วมกัน

## ข้อพบจากหน้าตัด

ภาพเทียบฉายหน้าตัดปีกกับNRต่างตำแหน่งตามแนวยาว จึงไม่ใช่การตรวจชน3Dหรือการแสดงคอนกรีตซ้อนจริง หน้าปีกกับNRมีช่องตามกริดเสนอ15มม. แต่ไม่ได้หมายความว่า15มม.เพียงพอสำหรับชุดTR

| ครอบครัว | Xที่ผิวนอกหลังคาปีกมีระดับ2850 จากขอบกริดซ้าย mm |
|---|---|
| A | 750 / 2250 |
| B | 428.786 / 2571.214 |
| C | 87.750 / 2912.250 |
| D | ไม่มีจุดตัดบนผิวหลังคาราบ; ผิวบน3000 ขอบเริ่ม200/2800 |

ใช้สูตรA=2700+0.2×min(X,3000−X); B=−900+sqrt(3900²−(X−1500)²); Cส่วนโค้ง=2600+sqrt(400²−(X−400)²)ฝั่งซ้ายและสะท้อนฝั่งขวา ด้านราบC/Dบน3000 ช่องกลาง20ยังต้องมีรายละเอียดแยก จุดตัดเป็นของผิวนอก ไม่ใช่เส้นรองรับหรือแนวตัดชิ้นงาน

A/Bมีระดับต่างกลับด้านระหว่างกลางกับริม; Cมีส่วนโค้งริมและช่วงราบ; Dใต้หลังคาปีก2850เสมอด้านบนNR แต่ระดับเสมอไม่ใช่จุดต่อสำเร็จ จึงต้องพัฒนาTRแยกตามครอบครัว รวมjoint movement/ส่วนปิดช่อง/flashing/ทางน้ำ ไม่ใช้แผ่นปิดสูงคงที่โดยอัตโนมัติ
