# P91 — แผนยกคอนกรีตครอบ 9 ชิ้นในท่าหล่อ P56

ขั้น **5/8**; งานย่อยนี้ไม่ใช่ระบบยกทั้งโครงการครบ100% และไม่เริ่มขั้น6

## เหตุผลและผลที่จัดทำ

P52 อ้างท่าหล่อเดิม แต่ P56 เปลี่ยนท่าหล่อครอบ/แผงปิดขอบให้เข้ากับแม่แบบจริง จึงต้องหาตำแหน่งยกและแนวเหล็กใหม่ในพิกัด P56 ไม่ใช่หมุนพิกัดเดิมแล้วคงทิศแรงโน้มถ่วงหรือแรงแต่ละขาเดิม

จัดทำครบ **CS1, CS2, CC, CE1, CE2, FS1, FS2, FE1, FE2** เป็นภาพจากโมเดล PNG/SVG และ JSON รายชิ้น รวม27ไฟล์ พร้อมทะเบียนและรายงาน HTML. Geometry น้ำหนัก และ CG ยึด P56 ซึ่งตรวจกลับ Typical ต้นทาง ไม่เปลี่ยนความหนาหรือรูปทรง

- โซนยก3แห่งอยู่บนผิวบนปัจจุบัน แรงยกแนวดิ่งสมดุลกับน้ำหนักและ CG; ไม่สมมติแบ่งน้ำหนักเท่ากัน
- แสดงแนวเหล็ก U สองทิศรอบแต่ละโซนรวม6แนวเชิงสัญลักษณ์ต่อชิ้น ไม่ระบุขนาด ระยะเรียง cover รัศมีดัด หรือระยะพัฒนาแรง
- ใช้สมมติกำลังยกคอนกรีตเพียงพอเพื่อพัฒนาตาม [คำตัดสินP52](decision-lifting-p52.json) โดยไม่ขอข้อมูลเดิมซ้ำ; verified capacity ยังคง null
- เส้นคานยกสีน้ำเงินเป็นผัง ไม่ใช่หน้าตัดหรือ hardware ที่ตรวจแล้ว จุดสีทองไม่ใช่พิกัดเจาะพุก
- กรณีความไวเพิ่มมวล10%ที่CGเดิมและคูณ1.3เป็นเพียงกรณีศึกษา ไม่ใช่ตัวคูณมาตรฐานหรือพิกัดอุปกรณ์

## การตรวจที่ทำจริง

ทดสอบ12รายการผ่าน:9ชิ้นรายตัว +ทะเบียน/ต้นทาง +ทดสอบปฏิเสธแนวเหล็กออกนอกชิ้นงาน +ทดสอบปฏิเสธแรงไม่สมดุลหรือสถานะอนุมัติผลิตที่ไม่จริง

ตรวจทุกแนวตรงด้วย convex half-space หลังยืนยันชิ้นงานเป็น convex solid; ตรวจวงพื้นที่ใต้จุดยกแบบต่อเนื่องด้วยสมการระยะถึงผิว ไม่ใช้การสุ่มจุดอย่างเดียว. นี่เป็นการตรวจเส้นแกนเชิงสัญลักษณ์ ไม่ใช่ระยะหุ้มเหล็กจริงหรือระยะขอบตามผู้ผลิตพุก

ตรวจทางถอนคอนกรีตขึ้น300มม.กับฐาน M00 ด้วย continuous SAT หลังแบบข้างและสิ่งยึดติดถูกปลดและพ้นแล้ว. ไม่ครอบคลุมแรงดูดติด การปลดช่วงเริ่มต้น การพลิก การชนสลิง/คานยก หรือทางเคลื่อนหลัง300มม.

ตรวจภาพด้วยสายตาครบ9ภาพ: ตัวอักษร/ตารางไม่ซ้อน รูปทรงตรงโมเดล แนวเหล็กเส้นประระบุเป็นภาพ X-ray และมีขอบเขตการใช้ชัดเจน
