# Stage 7 — P145: ผูกพื้นที่วัสดุปูพื้นกับแผ่นคอนกรีต

สถานะ: เตรียมข้อมูลเรขาคณิต ไม่ใช่ผลวิเคราะห์หรืออนุมัติผลิต

## ผลที่ทำแล้ว

- จับคู่ 320 พื้นที่วัสดุปูพื้นของ 48 แบบ กับ physical instance ของพื้นคอนกรีต P36 โดยตรวจ hash ของแหล่งโครงสร้างและ manifest งาน ARC
- ตรวจพื้นที่ซ้อนกับหน้าบนจริงของคอนกรีต รวมพื้นรูปเว้าที่โหนด L/U ด้วยการแบ่งสามเหลี่ยม ไม่ใช้กรอบสี่เหลี่ยมครอบแทนรูปร่างจริง
- ทั้ง 320 พื้นที่อยู่ในขอบเขตหน้าบนคอนกรีต ระดับใต้ finish ตรงกับหน้าบนคอนกรีต และไม่มีพื้นที่ finish ซ้อนกันภายในแต่ละอาคาร
- พื้นที่รวมตรงกับรายงานพื้นที่จาก Revit เดิมของทั้ง 48 แบบ ภายใน 0.000001 ตารางเมตร ไม่ได้เปิด Revit ตรวจใหม่ในรอบนี้
- 47 แบบใช้ polygon จาก P144/Recipe P104; I-B3 ใช้พิกัดจาก build_pilot.py ซึ่งตรวจข้อความสูตรต้นทางและบันทึก hash พร้อมเทียบพื้นที่รวมกับ Revit เดิม การตรวจนี้ไม่เท่ากับส่งออกขอบเขตจาก native model ใหม่
- บันทึกพื้นที่ จุดศูนย์กลาง และสัมประสิทธิ์แรง/โมเมนต์สำหรับแรงกระจายลง 1 kN/m² ไว้ต่อยอด ไม่ใช่ค่าน้ำหนักที่เลือกใช้ออกแบบ

## ขอบเขตที่ยังไม่เสร็จ

ค่าน้ำหนัก finish จริงยัง null เพราะต้องยืนยันชั้นวัสดุทั้งหมด ไม่ตีความความหนาจำลอง 10 มม. เป็นกระเบื้องตัน ยังไม่รวมการระบุตำแหน่งขา/จุดยึดอุปกรณ์และเฟอร์นิเจอร์ และยังไม่กระจายแรงไปยังหมายเลข plate ของ STAAD

การอยู่บนหน้าพื้นทางเรขาคณิตไม่รับรองกำลังพื้น จุดต่อ คาน หรือฐานราก ไม่มี reaction หรือ RC design ในชุดนี้ แกนผลชุดนี้คือ XY แนวราบและ Z ขึ้นของข้อมูลต้นทาง ต้องแปลงแกนก่อนส่ง STAAD

## ผลตรวจและส่งต่อ

เครื่องมือตรวจมีกรณี polygon กลับทิศ พื้นที่ซ้อนบางส่วน พื้นที่แยกกัน พื้นรูปเว้าและบริเวณรอยเว้าที่ไม่ควรมีพื้นที่ รวมถึงตรวจพื้นที่และแรงรวมของทุกอาคาร
