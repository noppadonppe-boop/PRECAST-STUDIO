# P29 — ครอบคอนกรีตและความสูงรวมไม่เกิน 3,000 มม.

ผู้ใช้เลือกชิ้นครอบคอนกรีตเพิ่มเติม และยืนยันความสูงรวมไม่เกิน3,000มม. จากใต้พื้นถึงผิวสูงสุดของชุดประกอบรวมครอบ ข้อกำหนดนี้มีลำดับเหนือข้อความเดิมที่นับถึงหลังคาหลักเท่านั้น ไม่มีการอนุมัติความหนาครอบหรือระยะติดตั้งเพื่อผลิต

## ข้อขัดแย้งที่ตรวจได้จากมิติ

กรณีศึกษาเดิม: หลังคาสูง3,000 + ช่องติดตั้ง20 + ครอบ100 =3,120มม. เกินข้อกำหนด120มม. ดังนั้นห้ามนำครอบดังกล่าววางบนยอดเดิมแล้วระบุว่าสูง3,000

หากใช้ครอบ100และช่อง20 พื้นผิวรองรับใต้ครอบบริเวณสูงสุดต้องไม่เกิน2,880มม. ค่านี้ยังไม่เผื่อผิวตกแต่ง ความลาดของครอบ หรือ tolerance จึงเป็นเพียงขีดจำกัดทางเรขาคณิต ไม่ใช่ระดับที่เลือกแล้ว

ห้ามแก้ด้วยการเจาะบ่าลึก120ลงในหลังคาหนาปกติ150โดยคงท้องเดิม เพราะเหลือเนื้อเพียง30มม. น้อยกว่าช่วงพัฒนา100–200มม. การเปลี่ยนระดับต้องรักษาความหนาของชิ้นงานและตรวจรูปทรงใหม่ทั้งด้านบนและท้องชิ้น

## สองแนวทางที่ต้องเลือกก่อนแก้ชุดมาตรฐาน

| แนวทาง | ส่วนที่คงเดิม | ผลกระทบ |
|---|---|---|
| ชิ้นเปลี่ยนระดับเฉพาะรอยต่อ L/U | หน้าตัดช่วงหลักและ Type I | เพิ่มชนิดชิ้น/แม่แบบ ต้องพัฒนาการเปลี่ยนระดับ ท้องชิ้น ทางน้ำและรอยต่อมุม |
| ลดระดับหลังคาหลัก I/L/U | แนวคิดหน้าตัดร่วมทั้งระบบ | ต้องแก้ซีกผนัง–หลังคา A/B/C/D แผงปลาย EPX ช่องใช้สอยและมวล รวมถึงระดับโหนด |

ข้อเสนอเพื่อพัฒนาต่อ: ศึกษาชิ้นเปลี่ยนระดับเฉพาะ L/U เพื่อรักษาหน้าตัดช่วงหลัก แต่ยังไม่ถือว่าได้พิสูจน์ความง่ายของแบบหล่อหรือความเหมาะสมทางโครงสร้าง ผู้ใช้ยังไม่ได้เลือกแนวทางนี้

## การควบคุมฉบับและสถานะ

- P21–P23 เก็บเป็นประวัติ ไม่ใช่ชุดครอบคอนกรีตที่ผ่านข้อกำหนดใหม่
- P28 มีแผง EPX 8ตัวเลือกที่ปรับช่องตั้งฉาก20และช่องฐาน10 พร้อมภาพ4แผ่นและการทดสอบ แต่ยังไม่ย้ายเป็นทะเบียนปัจจุบันระหว่างรอเลือกแนวทางความสูง หากลดหลังคาทั้งระบบต้องแก้แผงเหล่านี้อีก
- คงทะเบียนตรวจรับปัจจุบัน P27: ขั้น2/8 ที่80% (16/20) ไม่ยกผล85%ใน snapshot P28 เป็นความคืบหน้าที่ตรวจรับแล้ว
- P2-16 ต้องพัฒนาครอบ/ชิ้นเปลี่ยนระดับและทางน้ำ; P2-19 ต้องตรวจรวมฉบับที่เลือก; P2-20 ต้องปิดค่าพัฒนาและชุดส่งต่อ ก่อนรายงาน100%
- ไม่เริ่มขั้น3 ไม่รันออกแบบโครงสร้าง ไม่อนุมัติผลิต/ยก ผลต่างความสูงข้างต้นเป็นการประสานมิติเท่านั้น
