# P15 — ประกอบมุม N90 กับปีก TS-C สองด้าน

[3D ประกอบ](../../output/node-c-p15/N90-C-ASSEMBLY-P15.png) · [รูปตัดและบัญชีช่องเชื่อม](../../output/node-c-p15/N90-C-INTERFACES-P15.png) · [ทะเบียน](../../output/node-c-p15/register.json)

ขอบเขตเป็นจุดมุมเปิดS/E โหนด8ชิ้นตามP12/P13/P14 กับช่วงตรงTS-Cทึบตัวอย่างด้านละ1ช่วง รวม6ชิ้น ไม่ใช่L-C1ทั้งหลัง ไม่เลือกช่องหน้าต่างของผลิตภัณฑ์ และไม่เพิ่มTypicalใหม่จากยอด33รายการ

## พิกัดและสิ่งที่ตรวจ

ใช้localกริดโหนดX/Y=0..3000 และZจากใต้พื้น ใช้โปรไฟล์ซีกS00จากทะเบียนP05โดยตรง ไม่แทนด้วยกรอบกล่อง

- ปีกS: map(x,y,z)=(x,y−1492.5,z) ชิ้นยาว1485จบY−7.5
- ปีกE: map(x,y,z)=(3007.5+y,3000−x,z) หมุน−90° ไม่สะท้อนซีก
- ขอบNF/NRที่หน้าเปิดเว้น7.5จากกริด จึงได้ช่องตามแนวปีก15
- พื้นหน้าS มีช่วงขอบร่วมX195..2830 ยาว2635มม.
- พื้นหน้าE มีช่วงขอบร่วมY170..2805 ยาว2635มม.
- ช่วงขอบร่วมเป็นเพียงintersectionของขอบพื้น ไม่ใช่ช่องผ่านสุทธิ ความกว้างประตู หรือระยะรองรับ

รูปตัดตามแนวปีกที่พิกัดขวาง1000 อยู่นอกcrown joint20: ปีกTS-Cบน3000/ใต้2850 เทียบNRบน2850/ใต้2675 จึงมีระดับบนต่าง150และท้องหลังคาต่าง175มม. ไม่มีผิวสัมผัสตรงที่ออกแบบให้ถ่ายแรงระหว่างปีกกับNRในรูปนี้ ไม่ใช้การเสมอระดับ2850แทนจุดต่อ

3Dเป็นwireframeพิกัดเสนอ ไม่ลบเส้นซ่อน ไม่ใช่ภาพผลิตภัณฑ์สำเร็จหรือการแสดงลำดับติดตั้ง ผ่านการตรวจตำแหน่งปีกแยกจากกริดโหนดและสายมิติ ไม่ใช่full clash detectionของรายละเอียดที่ยังไม่ออกแบบ

## แยกงานชุดเชื่อม

- TR-C-STR: กรอบหัวช่อง ข้างช่อง มุมร่วม และระบบรองรับ/จุดยึด — geometryและขนาดยังnull
- TR-C-ENV: ปิดช่อง กันน้ำ การเคลื่อนตัว ฉนวน flashing และทางน้ำ รวมการปิดรอยต่อกลางหลังคา — ยังไม่เลือกระบบ
- TR-C-FLR: ขอบพื้นและปลายเหลื่อม25มม. — ไม่ถือว่าเติมยาแนวแล้วจบ
- TEMP/LIFT: การค้ำยันและติดตั้ง ตรวจDEM/ROT/ERECTรายชิ้นตามL01 ไม่อนุมัติยก14ชิ้นทั้งชุด

รายการข้างต้นเป็นกลุ่มงานที่ต้องออกแบบ ไม่ใช่Typicalชิ้นหล่อหรือแบบยึดต่อที่ส่งมอบแล้ว ไม่กำหนดเหล็กหรือเสาสมมติเพื่อปิดสถานะงาน

## สถานะและงานต่อ

ตรวจภาพ2แผ่นแล้ว ชุดทดสอบข้อมูลรวม78รายการผ่าน ระดับNR2850ยังไม่เลือก ไม่มีน้ำหนักอาคารครบ ไม่มีแบบจุดต่อ/ระบบกันน้ำ/กรอบรับหรือการอนุมัติผลิต ไม่รันโครงสร้างตามแผนผู้ใช้ เว็บR02/RVT/STDยังไม่ส่งมอบเพิ่ม

ขั้นต่อไปควรจัดทางเลือกพื้นที่กรอบรับและส่วนเชื่อมTR-Cให้เห็นผลต่อช่องใช้สอย ระดับหลังคา และจำนวนชิ้น ก่อนล็อกgeometryมุม ไม่ทำแบบแม่แบบผลิตโดยถือว่ารอยต่อ15และพื้นที่บนผนัง20เพียงพอโดยอัตโนมัติ
