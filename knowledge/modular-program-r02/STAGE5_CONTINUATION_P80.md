# P77–P80 — วิเคราะห์แถบต่อเนื่อง เพิ่มซี่ขอบ และแก้ทางถอด

ขั้น5/8 ตามขอบเขต P40 ครบ8ด้าน ยังไม่จบขั้น5 ไม่เริ่มขั้น6. รอบก่อนP75/P76เป็น progress เพราะอัปเดตบัญชีแรงและระบุบริเวณขอบต้องแก้ รอบนี้ต่อยอด geometry จากผลนั้นจริง

## P77: การถ่ายแรงต่อเนื่อง

[รายงานแถบ12รุ่น](../../output/abd-continuous-skin-p77/index.html) ใช้ solver continuous-beam-p49 ที่มี benchmark ไม่สร้างตัวใหม่โดยไม่จำเป็น. แถบ1mm, E200000MPa, p37.125kPa, supports translation-fixed / free rotation / displacement and rotation continuity. ตรวจจำนวนองค์ประกอบ1กับ4ต่อช่วงและสมดุล ไม่เรียก full plate/shell หรือ whole mould analysis. ทดสอบ21รายการรวม solver benchmark

เปรียบเทียบซี่เดิมกับซี่ห่างขอบ50mmในแบบคำนวณ พบว่า geometry จริงของ50mmชน seam plates/bolts จึงไม่เลือกไปใช้ ไม่ถือผลคานที่ดีเป็นหลักฐานสร้างได้

## P78–P80: Geometry ที่แก้จริง

[ข้อมูลปัจจุบันP80](../../output/abd-edge-ribs-p80/index.html): เพิ่มซี่ขอบที่150mm ยกเว้นปลายผนังในM03ใช้225mmเพื่อหลบหลังคาในและค้ำ หากมีซี่เดิมอยู่ภายใน200mmจากขอบใช้ซี่เดิม ไม่เพิ่มซ้ำ. A/Bเพิ่ม4ribs+6waler extension=10ชิ้น; Dเพิ่ม3ribs+6extension=9ชิ้น. เหล็กเพิ่มประมาณ71.792/71.783/55.802kg ตามลำดับ. คอนกรีตเดิมไม่เปลี่ยน

ส่วน EXT แสดงปริมาตรที่เพิ่ม ไม่ใช่ splice ที่ผ่านกำลัง ให้เปลี่ยน waler เดิมเป็นชิ้นเต็มตามความยาวรวมในแบบผลิต หรือออกแบบ splice แยกก่อนใช้. ยังไม่อนุมัติ weld/stock size

P78ตรวจ staticผ่านแต่ทางถอนSJ-M03-M04เดิม-Y300ชนซี่M03ใหม่. P79ลด-Y100แล้วX500 หลบซี่แต่ระดับล็อกL1 A/Bยังชนค้ำM04. P80เพิ่ม+Z600หลัง-Y100เฉพาะL1 A/Bก่อนX500; Dใช้P79. คง±Z100เดิมเพื่อปลดจากรูและแหวน ทิศXเข้าด้านในLH+500/RH-500

P80ครบ12รุ่น: static/tool76envelopes/เส้นทางส่วนเพิ่มผ่าน; A/Bทึบ333ช่วง หน้าต่าง371ช่วง; Dทึบ329/หน้าต่าง367ช่วง. เปลี่ยนเส้นทางhardwareตรวจต่อเนื่องเทียบกับทุกsolidที่ยังไม่ถอด ไม่ใช่ตรวจเฉพาะต้น–ปลาย. ยังคง P66/P71/P74 เป็นฐานตรวจชิ้นเก่า ไม่อ้างตรวจ old-old ใหม่ทั้งหมด

ใช้ **P66 + P71 + P74 + P80 ครั้งเดียว**; ไม่รวมP78/P79เพิ่มซ้ำ. ภายในJSON ribsกับstockอ้างชุดเดียวกัน ใช้stockเป็นบัญชีส่วนเพิ่มเท่านั้น. P78/P79ที่พบชนเก็บประวัติ ไม่อัปเกรดผลย้อนหลัง

## ขอบเขตผลแรง

อัปเดต continuous strip ตามตำแหน่งซี่จริงในP80และเปรียบเทียบผิว6/8/10mm. ตัวอย่างA-LH-S00ผิวM03ปัจจุบัน6mmให้ elastic deflection≈6.891mm ในกรณีรองรับที่แกนซี่สมมติและไม่ให้เครดิตseam (เกินความหนาจึงมีsmall-deflection warning). 10mm≈1.489mm. ไม่ใช่หลักฐานเลือก10mmแล้ว; ต้องตรวจการรองรับร่วม/เกณฑ์โก่งและribs/walersก่อนเปลี่ยนผิว

ผลยังไม่ครอบคลุมหน้าต่างระดับกลางและplate action; Bหลังคาเป็นflat substitution ไม่รับรองupper bound. nominalfy235ไม่ใช่allowable stress. ไม่มีcode PASS หรือกำลังยกยืนยัน
