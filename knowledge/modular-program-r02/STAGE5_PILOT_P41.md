# P41 — TS-C แม่แบบเหล็กพร้อม hardware / รูปทรงเหล็กเสริม

## คำสั่งล่าสุดและการตีความ

ผู้ใช้ให้ทำต่อให้ครบ และตอบระหว่างทำงานว่า: ความหนา Segment ใช้ตามขั้น2 ส่วนเหล็กเสริมให้เสนอรูปร่างก่อน ยังไม่ระบุขนาดเหล็ก คำตอบนี้ไม่ใช่ข้อมูลความหนา/เหล็กพื้นโรงงาน และไม่ยืนยันกำลังคอนกรีตในอายุยก

คงตัวอย่าง TS-C-H15-LH-W01-P05 หนา150mm และต้นทางคอนกรีตเดิม เริ่มพัฒนาฮาร์ดแวร์จริงโดยไม่แทนรูปเก่าในเว็บ ไม่ขยายทุก Typical และไม่เริ่มขั้น6

## สิ่งที่ยังไม่เสร็จ — ห้ามรายงานว่า100%หรือพร้อมผลิต

รายการคำนวณรอบนี้เป็น elastic screening และแรง demand ไม่ใช่ code strength check ครบ: ต้องปิด whole-frame stiffness/stability, HSS/local weld/flange prying/thread engagement, weld/mitre details, พื้น/พุกโรงงาน, tolerance/gasket/wrench access และผล prototype

ระบบยกมีรูปแบบสามแนวแรงและ sensitivity demand อ้าง CG คอนกรีตล้วน แต่ยังไม่เลือกพุก/คานยก/สลิง ไม่ตรวจการพลิกหรือรับรองกำลังยก เหล็กเสริมยังเป็นรูปทรงตามคำสั่งล่าสุด หูยกเหล็กในโมเดลยังต้องตรวจตำแหน่งเทียบCG/การเอียงและรอยเชื่อมก่อนใช้

ค่ามวล stock-sum ของชิ้นเหล็กนับซ้อนรอยตัดเชื่อมบางจุด และไม่รวมงานเชื่อม/สี/rigging ไม่ใช่น้ำหนักยกจริง ฟิลด์เดิม `steelMassUpperBoundKg` ในJSONของโมเดลนี้ต้องอ่านตามความหมาย stock-sum นี้ ไม่ใช่ upper bound ของเครื่องมือสำเร็จทั้งชุด
