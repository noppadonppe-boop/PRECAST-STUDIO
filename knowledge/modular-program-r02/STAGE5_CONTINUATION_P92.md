# P92 — จุดยึดขาผนัง: จับคู่แรง P90 และข้อกำหนดตรวจรับ

ขั้น **5/8 ยังดำเนินการอยู่**. งานนี้ใช้ผลที่รันและตรวจแล้ว ไม่รัน FE เพิ่ม ไม่แก้รูปทรง Typical ไม่เริ่มขั้น6/7 และไม่เปลี่ยนภาพหลัก P43

## ขอบเขตที่จะปิดในงานย่อยนี้

1. จับคู่แรงดึง P90 กับแรงเฉือน P85 ของโบลต์ตำแหน่งเดียวกันในกรณีแรงดันเดียวกัน ตรวจพิกัดและแรงรวมที่จุดอ้างอิงเดียวกันก่อนใช้: 24 กลุ่มขา / 96 โบลต์ใน A/B/D-LH/RH-W01
2. อัปเดตการตรวจตัวโบลต์และแรงกดรูแผ่นขาตามสูตรที่อ่านจากเอกสาร JRC ของ P88 พร้อมกรณี Leff40/60 เฉพาะจุดนำร่อง ไม่ขยายผลไป S00 หรือระบบทั้งหมด
3. สรุปการเลือกแหวน ISO7089-200HV คู่กับหัวหกเหลี่ยมชั้น8.8 และตรวจพื้นที่รองรับเชิงเรขาคณิตจริง แยกจากการดัดแหวนจริง/แรงอัดจากการขัน
4. จัดทำข้อกำหนดตรวจรับสกรู แหวน และเกลียวฐานจากกรอบ P89 โดยแยกมิติ nominal / เกณฑ์ตรวจรับที่เสนอ / สิ่งที่ต้องยืนยันกับสินค้าจริง
5. แยกข้อสรุปสำหรับแรงดันสถิตจากแม่แบบใช้ซ้ำอย่างชัดเจน ไม่ใช้ผล static ผ่านแทนความล้า/การคลายตัวหรือยกแม่แบบ

## ข้อสรุปที่ห้ามข้าม

แหวนมาตรฐานที่จับคู่ได้ช่วยปิดการเลือกประเภทผลิตภัณฑ์แบบมีเงื่อนไข แต่ไม่ทำให้ rigid patch ใน P90 กลายเป็นการตรวจการดัดแหวนจริง. ค่าเฉลี่ย T/พื้นที่ใต้แหวนเป็นข้อมูล demand เท่านั้น ไม่มี preload และไม่ใช่ความดันสูงสุด

P89 ยังเป็นทางเลือก. ระยะฝังรวม26–28มม.อยู่เหนือ25.22มม.ที่บันทึกจากเครื่องคำนวณผู้ผลิต แต่ไม่เท่ากับเกลียวเต็มที่มีผลทั้งหมด และไม่ใช่ allowable capacity. ไม่หารกำลังรูดจากวิธีผู้ผลิตด้วยตัวคูณ EC3 เพื่อสร้างกำลังรับได้แบบผสม

เอกสาร JRC PDF102 ไม่ให้ใช้ non-preloaded tension category D กับการแปรผันแรงดึงบ่อย. แม่แบบผลิตซ้ำจึงยังไม่ได้รับการยอมรับจากกรณีสถิตนี้ ต้องกำหนดระบบควบคุมการขัน/การล็อกและตรวจการใช้ซ้ำต่อ ไม่กำหนดค่า torque จากขนาด M20 เพียงอย่างเดียว ไม่แก้ปัญหาด้วยการกล่าวว่าเป็น single-use เพื่ออ้างจบแม่แบบมาตรฐาน

การตรวจระยะรูต้องอ่านเงื่อนไข exposure/compression ของตารางด้วย: M01=250, M03=240, แนวขวาง140มม. ไม่ประกาศว่าเกิน200ทำให้ทุกกรณีใช้ไม่ได้ หรือว่าอยู่ในอาคารแล้วผ่านทุกกรณี

## งานต่อที่ยังจำเป็น

แม่แบบใช้ซ้ำยังต้องกำหนดการควบคุมแรงขัน/ระบบล็อกและตรวจการใช้งานซ้ำ; ระบบฐาน/รอยเชื่อม/การรวมแรง/ยกแม่แบบและเสถียรภาพแต่ละช่วงยังต้องปิดต่อ. ผลของW01ไม่ครอบคลุมS00หรือชุดอื่น. ทำงานรายละเอียดที่ยังขาดจากP40ต่อ โดยไม่รันFEซ้ำเมื่อไม่มี input เปลี่ยนหรือเกณฑ์ไม่ผ่าน
