# การแยกภาพชุดเดิมและข้อมูลชุดใหม่

คำสั่งผู้ใช้: คลังแบบโมดูลาร์คอนกรีตกลับมาใช้รูปภาพเดิม และเก็บข้อมูลสร้างใหม่ในแท็บใหม่

- ค่าเริ่มต้นเมื่อเปิด /catalogue คือแท็บ **ภาพชุดเดิม** ใช้ภาพอาคาร R00/R01 จากคลังเดิม ไม่เปลี่ยนไฟล์ต้นฉบับ
- แท็บ **แบบและข้อมูลชุดใหม่** เก็บ 48 แบบมีมิติ P36, Typical P35, แม่แบบ/ภาพตรวจรูปทรง P38-R1, น้ำหนักและดาวน์โหลดเดิมทั้งหมด
- ภาพเก่าคงป้าย concept และ Type I เดิมคง LEGACY20 ไม่เปลี่ยนมิติภาพเก่าให้เป็นมาตรฐานใหม่
- คำสั่งนี้ไม่ยกเลิกการถอนภาพแม่แบบ AI ที่ไม่ตรงจริง ไม่คืนภาพนั้นเป็นหลักฐานผลิต
- ไม่เปลี่ยน API/สิทธิ์/สถานะ engineering หรือ geometry; เป็นการเปลี่ยนการจัดหน้าและค่าเริ่มต้นเท่านั้น
- งานปรับแท็บแยกจากความก้าวหน้าแม่แบบ ขั้น5ยัง50% ไม่เริ่มขั้น6
