# P49–P51 — เดินหน้างานค้างขั้น5โดยไม่ถามซ้ำ

ผู้ใช้สั่งให้ดำเนินงานค้างในขั้นปัจจุบันต่อจน100% ไม่ต้องขอคำสั่งต่อเมื่อจบงานย่อย. คงข้อกำหนดเดิม: ไม่เริ่มขั้น6เอง, ไม่เปลี่ยน Typical, ไม่กำหนดขนาดเหล็กเสริมคอนกรีตในรอบนี้, ไม่ถือว่าพื้นโรงงาน/พุกยกผ่านแล้ว.

## สิ่งที่เพิ่มในรอบนี้

1. [P49](../../output/floor-connections-p49/README.md): คานต่อเนื่องแผงข้างพื้น F2660/NF02, 24กรณีแผง/72ปฏิกิริยาสถานี. เปรียบเทียบ rigid/spring และแรงดึงทดลองตามขอบเท้าที่กดรับแรงจริงด้านนอก ไม่ใช้การหารเท่ากันแทน stiffness.
2. [P50](../../output/floor-workpack-p50/README.md): บัญชีเหล็ก60ชิ้นและhardware nominal36ชิ้นต่อแม่แบบทั้งสองขนาด, ผังเจาะและพิกัด12รู. ปริมาตรบัญชีเหล็กหลังหักรูตรงกับsolidต้นทาง.
3. P51: ขยายแม่แบบโต๊ะไปยังผนังโหนด NW01/NW02 และหลังคาโหนด NR-S/NR-N รวม4setup โดยตรวจเรขาคณิตต้นทางใหม่ทั้งหมด. แยกผลจากแม่แบบพื้นเดิม ไม่สืบทอด PASS.

## สถานะจริงของขั้น5

ตัวเลข50%เป็นตัวอ้างอิง checklist P38-R1 เดิม ไม่ใช่ความพร้อมผลิต. เก็บตัวเลขเดิมไว้โดยไม่เพิ่มเพราะจำนวนภาพ/สคริปต์เพิ่ม. มีโมเดลhardwareระดับพัฒนาครอบคลุม10จาก44setup (P41หนึ่ง + พื้นห้า + โหนดใหม่สี่), ยังไม่มีsetupใดครบการตรวจรับตามข้อ1–8ของP40. ห้ามรายงาน10/44ว่า22.7%ของขั้นหรือแทนตัวเลข50%.

งานภายในที่ยังค้าง: hardwareอีก34setup, load path/contact/prying/bolt/weldและความแข็งรวม, ซีล/ค่าคลาดเคลื่อน, ชิ้นส่วนจริงของระบบยก/พลิก, ตรวจชุดแบบและนำเข้าคลังเว็บตามสิทธิ์. งานเหล่านี้ไม่ได้ถูกย้ายไปขั้น7.

จุดที่ต้องใช้ข้อมูลจริงก่อนปิดผลสุดท้าย: สมบัติ/เกรดวัสดุและอุปกรณ์ที่จัดหา, เหล็กเสริมและกำลังคอนกรีตตอนยก, ระบบพุก/คู่มือเฉพาะรุ่น, พื้น/ฐานโรงงานและตำแหน่งใช้งาน, พิกัดเครนที่ระยะทำงาน. ผู้ใช้ไม่มีข้อมูลบางรายการแล้ว ไม่ถามซ้ำ; เก็บข้อกำหนดส่งต่อ P45 และไม่เติมค่ารับรองเอง.

ข้อขัดกันที่ต้องคงให้เห็น: ขอบเขตปัจจุบันให้เสนอเพียงรูปทรงเหล็กเสริม แต่ P40 ต้องตรวจการยกชิ้นคอนกรีตจริง. รูปทรงอย่างเดียวปิดกำลังยกไม่ได้. จึงไม่สามารถประกาศครบ100%ของP40ด้วยการทำเอกสารหรือภาพเพิ่ม และไม่ถือว่าคำสั่งทำต่ออนุญาตให้เลือกเหล็กอาคารแทนผู้ใช้.

## ทำซ้ำ

เรียกสคริปต์ `floor-mould-p46.mjs`, `floor-lock-p47.mjs`, `floor-demand-p48.mjs`, `floor-connections-p49.mjs`, `floor-workpack-p50.mjs` ใน `tools/modular-program/` ด้วย flag `--p51` ตามลำดับ. Flagนี้เขียนเฉพาะ output/table-*-p51 ไม่เขียนทับผลP46–P50. ห้ามรันพร้อมกันก่อนinputของขั้นก่อนหน้าสร้างครบ.

ทดสอบด้วย `node --test tools/modular-program/table-p51.test.mjs` ร่วมกับชุดทดสอบP48/P49/P50. ภาพเทคนิคสร้างจากmodel ไม่ใช้imagegenแต่งแรงหรือมิติ. ภาพสไตล์เดิม P43 และเว็บค่าเริ่มต้นไม่เปลี่ยน.
