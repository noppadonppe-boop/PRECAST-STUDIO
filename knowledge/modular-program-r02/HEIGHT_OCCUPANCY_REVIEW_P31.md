# P31 — ต้องทบทวนความสูงตามประเภทการใช้อาคารก่อน freeze

สถานะ: PRELIMINARY_REGULATORY_SCREENING / NOT_LEGAL_OR_PERMIT_APPROVAL

ตรวจเมื่อ17กันยายน2026 จากกฎกระทรวงฉบับที่55 พ.ศ.2543 ข้อ22 หน้าเอกสาร5 (PDFหน้า5) ที่เผยแพร่โดยกรุงเทพมหานคร:
https://webportal.bangkok.go.th/public/user_files_editor/95/ITA2566/O4/CI/ci-11.pdf

แหล่งนี้เป็นข้อความกฎหมายที่เผยแพร่โดยหน่วยงานรัฐ ไม่ใช่ผลตรวจข้อบัญญัติท้องถิ่นของพื้นที่ติดตั้งในระยองหรือความครบถ้วนของข้อยกเว้น/ฉบับแก้ไขทั้งหมดสำหรับแต่ละโครงการ

## ข้อที่ต้องนำไปตรวจ

ตารางข้อ22ระบุระยะดิ่งสำหรับที่พักอาศัย/ห้องพักโรงแรมกลุ่มหนึ่ง2.60ม. และสำนักงาน/ห้องอาหาร/โถงภัตตาคารกลุ่มหนึ่ง3.00ม. วิธีวัดมีหลักแยกกรณีพื้นถึงพื้น ชั้นใต้หลังคา และพื้นที่ในโครงสร้างหลังคา จึงห้ามแทนระยะดิ่งด้วยความสูงภายนอกจากใต้พื้นถึงยอดครอบ หรือแทนด้วยระยะใต้หัวกรอบโดยไม่ตรวจวิธีวัด

ร้านกาแฟและรีสอร์ทต้องจำแนกตามการใช้จริง ไม่เลือกหมวดจากชื่อสินค้าอัตโนมัติ และห้ามถือว่าเป็นโมดูลาร์/น็อคดาวน์แล้วได้รับยกเว้น

## ผลคัดกรองจากมิติของโครงการ

- กรอบภายนอกสูงสุด3000และผิวบนพื้นZ175 ทำให้ทุกจุดของอาคารสูงเหนือผิวพื้นได้ไม่เกิน2825มม.ก่อนปูพื้น ดังนั้นหากหมวดที่ใช้บังคับต้องการระยะดิ่ง3000 ย่อมเป็นข้อขัดแย้งที่แก้ด้วยรายละเอียดครอบหรือเหล็กเสริมไม่ได้
- โหนดP31มีท้องหลังคาZ2625 และยอดผนังZ2605: ระยะเหนือพื้นZ175คือ2450และ2430มม.ตามลำดับ ต้องให้ผู้รับผิดชอบพิจารณาจุดวัดของระบบนี้ ไม่รายงานว่าผ่าน2.60ม.จากยอดครอบ2989.7
- การยืนยันกฎหมายต้องแยกจากการทดสอบโค้ดเรขาคณิตซึ่งไม่ได้ตรวจการขออนุญาต

## ข้อมูล/การตัดสินใจที่จำเป็น

1. ระบุพื้นที่ติดตั้ง/องค์กรปกครองท้องถิ่น และประเภทการใช้จริงที่สถาปนิกหรือผู้รับผิดชอบยืนยัน
2. ตรวจวิธีวัดสำหรับระบบหลังคา–ผนังชิ้นเดียวและข้อกำหนดที่ใช้บังคับ พร้อมหลักฐานข้อยกเว้นหากมี
3. ผู้ใช้พิจารณาว่าอนุญาตให้ทบทวนความสูงรวมแยกตามการใช้หรือไม่ หรือจะคง3000เฉพาะกรณีศึกษารูปทรงที่ยังไม่รับรองการใช้งาน ไม่ถือการคงกรอบศึกษาเป็นการผ่านเกณฑ์มาตรฐานผลิตภัณฑ์

ยังไม่เปลี่ยนข้อกำหนด3000เอง และไม่ตัดสินค้าออกจาก48แบบเอง ประเด็นนี้ขัดกับการfreezeมาตรฐานเพื่อส่งต่อ ไม่ควรรอถึงขั้น7ซึ่งอาจทำให้ต้องแก้แม่แบบ/Revitทั้งหมด
