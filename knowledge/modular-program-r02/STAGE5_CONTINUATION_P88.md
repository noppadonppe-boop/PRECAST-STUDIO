## ฐานอ้างอิงและผล

อ่านตาราง/เงื่อนไขจาก European Commission JRC96658 (2015), DOI10.2788/605700, printed85–91/PDF101–107 และตรวจภาพตาราง2.4จริง เป็นเอกสารฝึกอบรมที่แสดงข้อ EN1993-1-8รุ่นเดิม **ไม่ใช่การตรวจcodeฉบับปัจจุบันและNational Annexครบ**. gammaM2=1.25เป็นค่ากรณีศึกษาที่ระบุ ไม่แทนมาตรฐาน วสท. ของอาคารและไม่เลือกฐานมาตรฐานแม่แบบฉบับสุดท้าย

เอกสารต้นฉบับอยู่ `references/JRC96658-2015.pdf` เพื่ออ่านในทีม ไม่ผูกเป็นartifactสาธารณะหรือใส่ในZIP; metadataเก็บURL/DOI/page/hashไว้. สูตรและเงื่อนไขที่ใช้ลงทะเบียนใน JSON

เสนอ **กรณีกำลัง M20 class8.8** เพื่อพัฒนารายละเอียดต่อ ไม่ใช่ยืนยันว่าhardwareเดิมเป็นเกรดนี้หรือสั่งซื้อแล้ว. ที่แรงดันคูณ1.5 ค่า governing ratioสูงสุด **0.456204** เกิดที่ D-RH-W01-M03-F2/B2, T=61.860kN และV=13.463kN ณตำแหน่งเดียวกัน. อีกกรณีclass4.6มีratioสูงสุด0.912409. ตัวโบลต์96/96อยู่ภายในตัวเลขresistanceกรณีศึกษานี้ **แต่ connectionPassedยังnull และverifiedCapacityยังnull**

แรงกดรูแผ่นขา: ผลรวมratioสององค์ประกอบแบบอนุรักษ์เพิ่มเติมสูงสุด0.075748. ไม่ใช้ตัวเลขนี้รับรองฐานรองรับหรือเกลียวในฐาน

## ประเด็นออกแบบที่ต้องปิดต่อ — ไม่ซ่อนด้วยผลผ่านตัวโบลต์

1. เกลียว M20ลึก20มม.ในฐาน30มม.ของP85ยังเป็นnominal envelope ไม่ใช่การรับรองpitch/tap drill/ชั้นความคลาดเคลื่อน/การรูดเกลียว ต้องออกแบบรับแรงและวิธีเปลี่ยนเมื่อสึก
2. แหวน22/40/3มม.ยังไม่ผ่านกำลังหรือความแข็ง; P86ใช้แหวนแข็งอุดมคติ ไม่ได้พิสูจน์แหวนจริง
3. Pitch250มม.ต้อง dispositionเรื่องข้อจำกัด200มม. **เมื่อเงื่อนไขexposure/compressionในตารางใช้บังคับ**. ระยะขอบขั้นต่ำผ่านไม่ได้ปิดระยะสูงสุดหรือการกัดกร่อน
4. แม่แบบใช้ซ้ำมีแรงดึงเปลี่ยน ต้องพิจารณาความล้า/ขัน/กันคลาย/จำนวนรอบ ไม่อ้างstaticรับรองการใช้งานซ้ำหรือเปลี่ยนเป็นpretensionโดยไม่ปรับโมเดล
5. ยังต้องตรวจรอยเชื่อม/ขา/โครงร่วมกันและกรณีgravity/handling/ฐานโรงงาน. ไม่ขยายผลไปS00, จุดยึดหลังคา/หัวท้าย/บล็อกช่องเปิด หรือ38setupอื่น
