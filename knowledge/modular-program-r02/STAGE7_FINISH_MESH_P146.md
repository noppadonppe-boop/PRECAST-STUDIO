# P146 — ส่งโหลดวัสดุปูพื้นจากเรขาคณิตเข้า STAAD: I-C1

วันที่ 2026-09-20 | ขั้น 7/8 | UNIT-LOAD STUDY ONLY ไม่ใช่ RC design

## งานที่เสร็จในรอบนี้

เชื่อม finish 4 แผ่นจาก P145 กับ mesh อ้างอิง P121 ได้ 756 plate และ 870 โหนดรับโหลด พื้นที่ 14.907518 m² ใช้แรงทดสอบ 1 kN/m² ไม่เลือกน้ำหนักวัสดุจริงแทนผู้ใช้

คำนวณแรงโหนดจากการอินทิเกรตฟังก์ชัน bilinear บนพื้นที่ซ้อนสี่เหลี่ยมจริง ตรวจแรงและโมเมนต์อันดับหนึ่งของแต่ละช่องและทั้งอาคารก่อนส่ง STAAD วิธีนี้ไม่ใช่การยืนยันว่าพฤติกรรมดัดเฉพาะที่เทียบเท่าคำสั่ง plate pressure ของ solver ต้องตรวจ load interpolation/refinement ก่อนนำแรงภายในไปออกแบบ

ใช้โครงสร้างและ joint แบบ RIGID REFERENCE เดิม รวมคุณสมบัติ E/ความหนาเดิม ไม่ใช่การเลือกจุดต่อจริง ไม่ใส่ selfweight หรือ load combination ในกรณีทดสอบนี้

## ผลรันและประเด็นแรงที่ฐาน

รัน native STAAD สามกรณีเก็บแยกโฟลเดอร์: โหลดโหนดตรง, ถ่ายโหลดไปโหนดควบคุมพร้อมโมเมนต์, และฉบับหลังที่เพิ่มผลแรงปลาย beam/แรงมุม plate เพื่อกู้แรงรวมของกลุ่มรองรับ

สองรอบแรกตาราง raw support reaction รวมแนวดิ่งประมาณ 13.129 kN เทียบโหลด 14.907518 kN จึงไม่ผ่านการตรวจจากตารางนั้น การถ่ายโหลดไป control ไม่ได้ทำให้ค่าตารางนี้เปลี่ยน จึงไม่สรุปว่าโหลดหายเพราะใส่ dependent node

ฉบับสุดท้ายใช้วิธีตรวจ P121: รวม native global element corner forces และ beam end forces ของทุกโหนดในกลุ่มรองรับ แล้วขนย้ายโมเมนต์มายังโหนดฐาน หักโหลดภายนอกบนกลุ่มถ้ามี ไม่บวก raw reaction ซ้ำ

ผลฉบับตรวจครบ:

- STAAD จบ; warnings 0 / errors 0
- แรงดิ่งลง 14.907518 kN; แรงรับรวม 14.907530 kN
- residual แรงทั้งสามแกนสูงสุด 0.0126 N (เกณฑ์เดิม 5 N)
- residual โมเมนต์ทั้งสามแกนสูงสุด 0.079032 N·m (เกณฑ์เดิม 10 N·m)
- ตรวจสมดุลรายสมาชิก 7,916 plate และ 152 beam; residual แรงสูงสุด 0.012 N และโมเมนต์ 0.009575 N·m
- ไม่ใช้ raw support reaction เป็นผลส่งทีมฐานรากของโมเดล rigid-group นี้
