# TS-C Master P01 — พิกัดหน้าตัดตั้งต้น

เริ่ม P2 โดยแยกความถูกต้องเรขาคณิตจากการรับแรง ไม่ได้รัน solver
หน่วย mm; X ขวางอาคาร, Y ตามยาว, Z แนวดิ่ง; origin ที่มุมซ้ายใต้พื้นของกรอบโมดูล

| รายการ | ค่า |
|---|---:|
| X ภายนอก | 0–3000 |
| Z ใต้พื้น / บนพื้นโครงสร้าง | 0 / 175 |
| Z หลังคานอก / ใน บริเวณราบ | 3000 / 2850 |
| X ผิวผนังใน ช่วงตรง | 150 / 2850 |
| ศูนย์โค้งซ้าย / ขวา (X,Z) | (400,2600) / (2600,2600) |
| รัศมีโค้งนอก / ใน | 400 / 250 |
| ความกว้างภายในช่วงผนังตรง | 2700 |
| ความสูงภายในใต้หลังคาราบ ก่อนตกแต่ง | 2675 |
| แนวแบ่งซีกหลังคา nominal | X=1500 |
| กริดตามยาว | 1500 |

โค้งเป็น quarter circle สัมผัสผนังตรงและหลังคาราบ; ความหนาวัดตาม normal 150 ไม่ใช่ลดระดับในแนวดิ่งตลอดแนวโค้ง
ซีกซ้ายเชิงเรขาคณิต: ผนังนอก (0,175)→(0,2600), โค้งศูนย์(400,2600) ถึง(400,3000), หลังคาถึง(1500,3000); ผิวในย้อนจาก(1500,2850)ถึง(400,2850), โค้ง R250 ถึง(150,2600), ผนังถึง(150,175)
ซีกขวาสะท้อนรอบ X1500; การสะท้อนนี้ไม่รับรองเหล็กหรือจุดยกสมมาตร

รายการนี้เป็น nominal envelope เท่านั้น ยังไม่กำหนด crown gap, bay gap, base bearing clearance, ความยาวชิ้นหล่อ, ความกว้างพื้นหล่อ, tolerance, slope ระบายน้ำ, ผิวตกแต่ง และช่องเปิด
ระดับเท้าผนัง Z175 เป็นข้อเสนอเพื่อประสานรูปหน้าตัดกับพื้น ไม่ได้ออกแบบการรองรับหรือถ่ายแรงลงพื้น (ยังคง LP-A รองฐานแยก)
ห้ามออกแบบหล่อจริงจากพิกัดนี้จนแก้ระยะรอยต่อและรายละเอียดประกอบ; รหัส TS-C-H15-LH/RH และ F15 ต้องผูก geometry revision เมื่อสร้างโมเดลจริง
