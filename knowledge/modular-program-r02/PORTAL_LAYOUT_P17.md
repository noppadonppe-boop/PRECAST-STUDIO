# P17 — เลือกทิศทางจัดพื้นที่ชุดมุม

[ภาพเปรียบเทียบ](../../output/portal-layout-p17/PORTAL-LAYOUT-P17.png) · [ทะเบียน](../../output/portal-layout-p17/register.json)

เป็นการเปรียบเทียบทางสถาปัตยกรรมจากพิกัดP15/P16 ไม่ใช่การรับรองระบบโครงสร้างหรือเลือกหน้าตัด วัสดุ และจุดต่อ ไม่เพิ่มTypicalหรือแก้แผงP12–P14ย้อนหลัง

## 1 WALL_SHARED — ใช้พื้นที่ขอบผนังร่วม

ศึกษาพื้นที่รับที่ปลายSIDE1และN2ภายในเนื้อผนังเดิม175มม. ไม่เพิ่มเสาทับคอนกรีตเดิมสองตำแหน่ง แต่ต้องออกแบบขอบผนัง/เหล็ก/จุดต่อ/ฐานใหม่ ไม่ถือว่าผนังเดิมรับแรงจากกรอบได้แล้ว

ยังมีพื้นที่เสาสมมติมุมร่วมP2 (X2800..3000,Y0..200) ชนNF01ขนาด192.5×192.5×175มม. จึงยังต้องแก้รูปทรงพื้นเมื่อเลือกทิศทางและตรวจระบบแล้ว ส่วนการเสริมขอบผนังอาจทำให้ต้องปรับNF02หรือส่วนอื่นเพิ่มภายหลัง

ช่องระหว่างพื้นที่แนวดิ่ง2625มม.; เมื่อตัดกับช่วงขอบพื้นเดิมเหลือ2605มม. ทั้งสองไม่ใช่ช่องผ่านสุทธิหรือระยะรองรับที่รับรอง

## 2 SEPARATE_FRAME — กรอบแยก

ใช้พื้นที่เสาสมมติ200×200สามตำแหน่งตามP16 ต้องประสานNF01/NF02และผนังSIDE1/N2ให้หลบ รวมระยะประกอบซึ่งยังไม่กำหนด กรอบและฐานยังต้องออกแบบ ไม่ได้แปลว่าปลอดภัยกว่าแนวทาง1

ช่องระหว่างพื้นที่แนวดิ่งและช่วงขอบพื้นร่วม2600มม. ก่อนรายละเอียดรอยต่อและตกแต่ง ไม่ยืนยันช่องผ่านสุทธิ

## สิ่งที่ไม่ควรสรุปจากภาพ

- จำนวนพื้นที่เสาไม่เท่าจำนวนชิ้นผลิตจริง แนวทาง1อาจต้องเพิ่มชิ้นขอบ/กรอบหรือเปลี่ยนวิธีหล่อ
- ส่วนต่าง25มม.ระหว่างกรอบพื้นที่ ไม่เท่าประโยชน์ช่องใช้งาน25มม.: ช่วงขอบพื้นร่วมต่างกันเพียง5มม.ในสมมติฐานนี้
- ทั้งสองยังต้องมีหัวกรอบ ความสูงก่อนตกแต่งจากหัวลึก100/200ในP16ยังเป็น2400/2300มม. ไม่ได้แก้ปัญหาความสูง
- material/memberSection/mass/finishedOpeningยังnull ไม่มีหูยกกรอบหรือการอนุมัติยก
- ไม่ได้ตรวจโครงสร้าง จุดต่อ bearing การโก่ง ไฟ แรงด้านข้าง หรือข้อกำหนดใช้สอย การเลือกทางพัฒนาไม่ใช่การอนุมัติผลิต

## จุดตัดสินใจ

แนวทาง1สอดคล้องเจตนาเดิมที่ให้ผนังมีบทบาทรับแรง แต่ความเป็นไปได้เชิงโครงสร้างยังต้องตรวจ แนวทาง2เปลี่ยนการจัดชุดมุมเป็นกรอบแยกที่ต้องหลบในแผง ยังไม่เลือกแทนผู้ใช้เพราะส่งผลต่อรูปทรงแผง แบบแม่แบบ และโมเดลถัดไป

ให้ผู้ใช้เลือกว่าอยากพัฒนาแนวทาง1หรือ2ก่อน แล้วสร้างgeometry revisionสำหรับประสานงานโดยยังไม่อนุมัติผลิต หากต้องล็อกแม่แบบจริง ต้องให้วิศวกรผู้รับผิดชอบทบทวนระบบก่อนตามข้อจำกัดP16

ตรวจภาพแล้ว ทดสอบข้อมูลรวม86รายการผ่าน ไม่ใช่การคำนวณโครงสร้าง เว็บR02/RVT/STDและFirebaseไม่มีการเปลี่ยนแปลงในรอบนี้
