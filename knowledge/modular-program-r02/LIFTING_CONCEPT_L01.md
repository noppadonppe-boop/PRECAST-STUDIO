# L01 — พื้นที่เสนอสำหรับจุดยก ไม่ใช่แบบยก

เพิ่มข้อกำหนดจุดยกให้ Typical ทุกครอบครัวและแบบประกอบทุกหลัง ต้องแยกขั้นถอดแบบ (DEM), พลิกชิ้น (ROT), ขนย้าย/ติดตั้ง (ERECT) และตรวจต่อชิ้น ไม่ใช้จุดยกทั้งอาคารแทน
ข้อมูลปัจจุบันยังไม่พอเลือกจำนวนจริง พิกัด ขนาด/รุ่น หรือกำลังหูยก ภาพ L01 จึงแสดงโซนที่ต้องศึกษาเท่านั้น ห้ามติดตั้ง/ยกตามภาพ

## ตำแหน่งที่เสนอให้เริ่มศึกษา

| ชิ้น | โซนศึกษา | ข้อควรระวัง |
|---|---|---|
| H15 ซีกผนัง–หลังคา | กระจายตามความยาวช่วงบนเนื้อคอนกรีตทึบ ฝั่งใกล้ผนังและฝั่งหลังคา ให้ระบบแขวนคร่อมจุดศูนย์ถ่วงจริง | ซีกงอไม่ใช่แผ่นสมมาตร; จุดบนหลังคาอย่างเดียวอาจทำให้เอียง ต้องศึกษาคานกระจายแรง/riggingและวิธีหมุนชิ้น |
| H15-W01 มีหน้าต่าง | พื้นที่ทึบนอกมุมช่องและนอกแถบแคบข้าง/เหนือช่อง | คำนวณ CGใหม่ ห้ามนำพิกัดS00ไปใช้โดยไม่ตรวจ; อย่าเลือกบนขอบหน้าต่างหรือโค้งโดยอาศัยภาพ |
| F15 พื้น | โซนด้านหน้าบนแผ่น กระจายรอบCGทั้งสองทิศทาง | รูป4โซนไม่ยืนยันใช้4anchorหรือแบ่งแรงเท่ากัน; ต้องตรวจ embedment ใน175มม. และแรงถอดแบบ |
| EP-S01 ปิดปลายทึบ | ERECT ศึกษาแนวส่วนบน/ขอบบนที่มีเนื้อคอนกรีตและระยะฝังพอ; DEM/ROT อาจต้องระบบคนละชุด | ห้ามเลือกหูยกขอบบนโดยไม่ตรวจทิศแรงและเหล็กเสริม |
| EP-D01 มีประตู | โซนเหนือเนื้อทึบสองข้างช่องเป็นพื้นที่ศึกษา | แถบเหนือประตู225มม.ยังไม่พิสูจน์ว่ายึดanchorได้; หากไม่พอเปลี่ยนแบ่งชิ้นหรือวิธีจับยก ไม่แก้ด้วยการเพิ่มหูยกเฉยๆ |
| NR/NW/TR และ A/B/D | ใส่รายการต้องออกแบบจุดยกในทะเบียน | ไม่ถ่ายตำแหน่งจากTS-Cโดยอัตโนมัติ; รอ geometry/mould orientation |

## ข้อมูลที่ต้องมี ก่อนออกพิกัดยก

น้ำหนักและCGตามชิ้น/ช่องเปิดจริง, ท่าหล่อ/ถอด/หมุน/ติดตั้ง, กำลังคอนกรีตขณะยก, แรงติดแบบ, มุมสลิง, dynamic effects, rigging/load sharing, ระยะขอบ/ช่อง/anchor, ความลึกฝัง/เหล็กเสริมเฉพาะ, กำลังชิ้นส่วนในสภาวะชั่วคราว, craneและค้ำยัน
ไม่ใช้ fc′28วันแทนกำลังขณะยก; ไม่สมมติ4หูรับแรงคนละ25%; ไม่ใช้เหล็กงอทำหูยกหรือการเชื่อมหน้างานที่ยังไม่ออกแบบแทนระบบที่ตรวจแล้ว
เลือก anchor/clutch ที่เข้าชุดและตรวจตามคู่มือผู้ผลิตสำหรับทิศแรงนั้น; หูยกไม่ได้เป็นจุดยึดกันตกบุคคล
หลังยกต้องออกแบบการปิด pocket/กันน้ำ/ป้องกันสนิมโดยเฉพาะหลังคา
