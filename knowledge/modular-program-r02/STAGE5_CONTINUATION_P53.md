# ขั้น 5 — P52/P53: เงื่อนไขยกคอนกรีตใหม่และรวมข้อมูลขึ้นคลัง

## ข้อตกลงล่าสุด

อ่าน [decision-lifting-p52.json](decision-lifting-p52.json): ผู้ใช้ให้สมมติกำลังยกคอนกรีตเพียงพอเพื่อพัฒนาแบบ และแสดงแนวเหล็กโดยไม่ใส่ขนาด จึงไม่รอขนาดเหล็กหรือผลกำลังอายุยกเพื่อจัดทำภาพระดับพัฒนาอีก ข้อความ P51 ที่หยุดงานพัฒนาเพราะข้อมูลเหล่านี้ให้ใช้ข้อตกลงใหม่นี้แทน ไม่แก้ประวัติ P51

สมมติฐานไม่ใช่ผลตรวจรับแรง พุก/สลิง/คานยก/ฐานโรงงาน/เครนยังไม่ถือว่าผ่าน ส่วนงานแม่แบบใน P40 ยังอยู่ขั้น5 ไม่ย้ายไปขั้น7หรือเริ่มขั้น6

## งานเพิ่ม

- [P52 — 44 ชิ้น](../../output/concrete-lift-p52/index.html): รูป 3D จากผิวต้นทาง, มวลคอนกรีต, CG, โซนศึกษา3จุด, แนว U เฉพาะจุดสองทิศ, แรงแนวดิ่งจากสมดุล และ PNG/SVG/JSON รายชิ้น รวม132ไฟล์
- เหล็กเป็นเส้นทางเชิงสัญลักษณ์ ไม่ใช่จำนวนเหล็กจริงหรือ BBS; Ø/spacing/cover/bend radius/development length เป็น null ไม่ได้เสนอขนาดโดยอ้อมผ่านภาพขยาย
- ระบบยก3จุดเป็นข้อเสนอสำหรับการแขวนอิสระแนวดิ่งในท่าหล่อ หลังปลดแบบและแรงยึดติดหมดแล้วเท่านั้น ไม่ใช้ผลนี้แทนแรงดึงให้หลุดแม่แบบหรือการพลิกตั้ง
- กรณี G ใช้มวลคอนกรีตเดิม; sensitivity ใช้มวลเพิ่ม10%ที่ CG เดิม ×1.30 เป็นสมมติฐาน ไม่ใช่ตัวคูณโค้ดหรือมวลยกที่รับรอง ไม่รวมมวลคานยก/สลิง
- โซน3จุดอยู่บนผิวบนที่คำนวณจาก mesh แต่ระยะขอบเพียงการตรวจเรขาคณิต ไม่ใช่ระยะที่คู่มือพุกอนุมัติ ห้ามใช้เป็นพิกัดเจาะ
- P53 เชื่อมไฟล์แม่แบบ/จุดล็อก/ผังเจาะ/ผลตรวจที่มีแล้ว P41–P51 จำนวน83รายการ ครอบคลุม10 setup เข้าหน้ารายชิ้น ไม่สร้างภาพให้34setupที่ยังไม่มีhardwareดูเหมือนเสร็จแล้ว
- คงภาพ P43 และภาพชุดเดิมเป็นประวัติ/ค่าเริ่มต้นตามที่ผู้ใช้เลือก; เพิ่มงานใหม่ในแท็บแม่แบบของชุดข้อมูลใหม่ พร้อมสิทธิ์ดาวน์โหลดฝั่งserver ไม่เปิดสาธารณะ/Firebase

## หลักฐานตรวจและขอบเขต

`tools/modular-program/concrete-lift-p52.test.mjs`: 47 tests ตรวจต้นทาง44รายการ, สมดุลแรง/โมเมนต์, CG, แยก void/ผิวลาด, จุดบนผิว และแนวเหล็กในเนื้อคอนกรีตด้วยการสุ่มจุดละเอียด ไม่ใช่ตรวจ cover/กำลัง/เส้นทางหมุนทั้งหมด

`tools/catalogue/verify-p53-browser.mjs`: ตรวจดาวน์โหลด PNG/SVG/JSON, ปฏิเสธanonymous, P41ปรากฏในหน้าที่ถูกต้อง, มือถือไม่ล้น และภาพเดิมคงอยู่ ผลจริงเก็บใน output/stage5-library-p53/qa

หลักอ้างอิงเลือกพุก: [Leviat HD socket technical document](https://www.leviat.com/en-be/mwdownloads/download/link/id/426.pdf) แยกเงื่อนไขกำลังคอนกรีตอายุยก ระยะขอบ และทิศแรง ไม่ได้นำตารางรุ่นใดมารับรองแบบนี้
