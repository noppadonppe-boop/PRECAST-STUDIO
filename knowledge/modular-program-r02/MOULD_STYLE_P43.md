# P43 — รูปแบบภาพแม่แบบที่ผู้ใช้ยืนยัน

ผู้ใช้อนุมัติรูปแบบภาพตัวอย่าง P42 ให้ขยายครบทุกชิ้นงานและบันทึก Skill ใช้ซ้ำ ไม่ได้อนุมัติความแม่นยำของรูปทรงที่ AI สร้างหรือการรับแรงของแม่แบบ

- ใช้ขาว/น้ำเงินกรมท่า/ผิวสัมผัสสีเงิน/insert เหลือง/คอนกรีตเทา ภาพแม่แบบซ้ายและชิ้นงานขวา
- ส่งหนึ่งภาพต่อ setup ในทะเบียน P38 รวม 44 รายการ ซึ่งใช้ร่วมในสินค้า 48 แบบ ไม่ใช่ 48 แม่แบบไม่ซ้ำ
- ใช้ภาพเรขาคณิตของแต่ละรายการแยกกัน ห้ามนำรูปทรง TS-C ไปแทนครอบ/พื้น/ผนังหรือครอบครัวอื่น
- เฉพาะ TS-C-H15-LH-W01-P05 มี hardware model P41 รายการอื่นยังแสดง contact surfaces ไม่อ้างว่าออกแบบชุดล็อก/ค้ำ/ระบบยกแล้ว
- ภาพ AI เป็น presentation เท่านั้น มิติและเรขาคณิตให้ใช้โมเดลต้นทาง ไม่ใช่ผลตรวจการชนหรือแบบผลิต
- เก็บภาพเดิมและข้อมูลคำนวณเดิม ไม่แก้ทับ เปิดภาพใหม่พร้อมคำเตือนและดาวน์โหลดแยกจากต้นทาง

ชุดไฟล์: `output/mould-style-p43/` มี jobs.json เก็บ prompt และ source hash รายชิ้น, manifest.json, index.html และ PNG

Skill โครงการ: `skills/precast-mould-presentation/SKILL.md` และสำเนาติดตั้งใน personal skills

ส่งภาพครบ 44 รายการ ตรวจเทียบภาพต้นทางครบในระดับ presentation แก้ภาพ pilot ที่ช่องหน้าต่างหาย/มีชิ้นส่วนเกิน และพื้น NF01-N01 ที่ผิดรูป ไม่อ้างว่าภาพตรง CAD ทุกพิกัด

เชื่อม P43 เข้าหน้าแม่แบบผ่าน authenticated artifact route เดิม แสดงภาพใหม่เป็นภาพนำเสนอและคงภาพเรขาคณิต/มิติเดิมด้านล่าง ไม่เปลี่ยนหน้าแรกภาพชุดเดิม ทดสอบ 44 รายการ, ดาวน์โหลด PNG, การปฏิเสธสิทธิ์ engineering และหน้า mobile แล้ว

ความคืบหน้างานปรับภาพแยกจากขั้นที่ 5/8 ทางวิศวกรรม ซึ่งยัง 50% ไม่เริ่มขั้นที่ 6 อัตโนมัติ และไม่เปลี่ยน productionReleased
