# P130-R1 — แก้การรันและตรวจชุดอ้างอิง Type I A/B/D

ขอบเขต: แก้การรัน STAAD และพัฒนาแนวคาน/บ่ารับตามที่ผู้ใช้อนุญาต ไม่ใช่เลือกความแข็งรอยต่อจริงหรือออกแบบ คสล. เสร็จ

## สิ่งที่แก้และหลักฐาน

- สร้างโมเดลอ้างอิง Type I A/B/D × 4 การใช้งาน รวม12แบบจาก P129: shell/plate, คาน250×400มม., แกนคานเข้า125มม., 6จุดรองรับแบบ PINNED ทดลอง ไม่มีดินรองรับต่อเนื่อง
- รอยต่อและระยะเยื้องใช้ rigid reference อย่างเปิดเผย; ผนัง END ยึดกับพื้นแบบทดลอง ไม่มี tie กับขอบหลังคา/ผนังข้าง บ่ารับจริงและกำลังยังไม่ได้ออกแบบ
- รัน D1 ครั้งแรกพบ badly shaped plate4ตัว: 2280,2373,4099,4195 จุดฉายใต้ผนังปลายห่างขอบพื้น1.709677มม. ทำให้มุมสามเหลี่ยมสูงสุด177.388° การตรวจ edge ratio เดิมไม่จับปัญหานี้
- เพิ่มจุดตามขอบพื้นเฉพาะบริเวณใกล้จุดฉาย ไม่เลื่อนจุดผนังหรือเปลี่ยนมิติชิ้นงาน ไม่เปลี่ยนรอยต่อพื้นตามขวาง ปริมาตรแต่ละpartคงเดิมภายใน1e-8ม³ จับคู่END-floorครบ368จุดใน12แบบ
- เพิ่มตัวกรองมุมสามเหลี่ยม <5° หรือ >165° เป็น project screening ไม่ใช่ข้อกำหนดโค้ดหรือ mesh convergence เกณฑ์ใหม่จับตาข่าย D1 เดิมได้4flagsตรงกับคำเตือนnative; meshใหม่ไม่มีflags
- แก้ตัวอ่านผล beam end forces ให้หยุดก่อนตาราง plate stresses; ตรวจเลขสมาชิก/โหนดและจำนวนแถว ป้องกันอ่านคนละตาราง และให้ verifier exit failure หากสมดุลไม่ผ่าน
- เก็บผลรันเดิมรวมทั้งรอบที่มีคำเตือน ไม่เขียนทับ ผลแก้เก็บ `output/staad-p7-p130-r1` และ meshแก้ `output/staad-p7-p130-remesh`

## ผลตรวจจริง

- แรงคงเหลือทั้งอาคารสูงสุด0.235776N <5N
- โมเมนต์คงเหลือสูงสุด0.773421Nm <10Nm
