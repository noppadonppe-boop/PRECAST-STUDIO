## วิธีและขอบเขต

- ใช้แรงปฏิกิริยาจากแถบผิวP80ที่ฐาน37.125kPa แปลงเป็นโหลดตามความสูง p(z)=25(1485-z)/1000 kPa โดยเก็บหน่วยแถบN/mmให้ชัด ก่อนอินทิเกรตเป็นแรงต่อซี่จริงN
- ซี่จริงอยู่Z30..1485. ไม่จัดสรรแรงผิวZ0..30เข้าโมเดลนี้ ต้องตรวจการถ่ายแรงลงฐาน/รอยต่อแยก ไม่แอบอ้างสมดุลผิวเต็มชิ้น
- สมมติคานรับซี่ที่Z150/700/1350ยึดการเลื่อน แต่ไม่ยึดมุมหมุน เป็นการแยกชั้นแบบทางเดียว ยังไม่ได้แก้ความยืดหยุ่นโครง/ค้ำ/ฐานร่วมกัน
- คำนวณหน้าตัดจากpolygonเหล็กจริงของซี่ ไม่คิดผิวเหล็กร่วมเป็นcomposite. ใช้tensorของพื้นที่หน้าตัดและการดัดไม่สมมาตรสำหรับprofiled box ไม่แทนBด้วยRHSสำเร็จรูปตรงโดยอัตโนมัติ
- พิกัดสถานีผลิตRHสืบทอดจากLH: ใช้ normal ที่ตำแหน่งLHก่อนสะท้อนX ไม่ใช้จุดเริ่มของRH contact-chain ซึ่งกลับลำดับ. ตรวจแรง/หน่วยแรง/section inertiaของคู่mirrorแล้ว
- คงข้อจำกัดโหลดผิวโค้งBจากP80 (flat-strip substitution) ไม่อ้างว่าเป็นupper boundหรือcoupled shell solution

## Solver และ QA

เพิ่ม linear-beam-p81 สำหรับแรงกระจายเชิงเส้น: Hermite beam / consistent nodal loads / exact load-bubble correction / หาmoment extremaจากรากshear ไม่ใช้sampleอย่างเดียว. คงไฟล์P49เดิมไม่เปลี่ยนเพื่อรักษาhashผลP77. ใช้การแก้สมการscaled eliminationแบบเดียวกับP49

16testsผ่าน: UDLเทียบP49, triangular hand check, mesh1↔4, sign/superposition, invalid support rejection, polygon sectionstrong/weakและrotation, 6ชุดสมดุล/แรงรวม/แหล่งข้อมูล, 3คู่mirror, ป้องกันเรียกW01เป็นS00

พบทดสอบmoment peakไม่ผ่านช่วงพัฒนาเพราะการสุ่มจุดข้ามตำแหน่งสูงสุด จึงเพิ่มรากshearจริง ไม่แก้ด้วยการผ่อนเกณฑ์. Preliminary B-RH ใช้normalคนละสถานีกับLHแล้วผลต่างกัน แก้mappingก่อนออกรายงานครั้งนี้

ผลซี่ในกรณีนี้ stressสูงสุดประมาณ9.45–9.52MPaและprojected deflection≈0.017mm ไม่ใช่ผลโก่งผิวแม่แบบทั้งหมด. ห้ามบวกผลผิวกับซี่แล้วเรียกว่าcoupled analysis และไม่อ้างกำลังผ่านเพราะตัวเลขต่ำ

พื้นฐานองค์ประกอบอ้างอิงประกอบ [TU Delft Euler–Bernoulli elements](https://teachbooks.tudelft.nl/computational-modelling/structural_linear/euler_bernouilli.html) เป็นแหล่งวิธีเชิงตัวเลข ไม่ใช่ข้อกำหนดกำลัง/allowable stressหรือการรับรองวสท.
