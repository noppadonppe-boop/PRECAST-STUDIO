# P138 — ยืนยันฐานวัสดุและสถานะการเข้าถึงมาตรฐาน

บันทึก 2026-09-18 ต่อ P134/P137 โดยไม่แก้ประวัติเดิม

## คำยืนยันของผู้ใช้

จากข้อความ “ยืนยัน ทั้งสามข้อ ข้อสามไม่มีข้อยกเว้น”:

- ยืนยันคอนกรีตน้ำหนักปกติ fc′350 ksc cylinder, เหล็ก SD50, ไม่อัดแรงล่วงหน้า และคานขอบหล่อในที่ต่อเนื่อง เป็นฐานระบบที่จะพัฒนาออกแบบ ไม่ต้องถามยืนยันรายการเหล่านี้ซ้ำ
- ขอบเขตพื้นที่ต้องครอบคลุมไทยทั้งสี่ภาคและ AU โดยไม่มีข้อยกเว้นพื้นที่เป็นเป้าหมายงาน ห้ามลดขอบเขตโดยตัดพื้นที่ออกเอง ทั้งนี้ยังต้องกำหนดพารามิเตอร์ภัยธรรมชาติ สภาพพื้นที่ ความคงทน และตรวจความเหมาะสมรายพื้นที่จริง ไม่ถือว่าโมเดลเดียวผ่านทุกพื้นที่แล้ว หากต้องเปลี่ยนรูปทรง/ขนาดต้องเสนอผลกระทบก่อน
- การยืนยันไม่ได้ทำให้ได้รับไฟล์หรือสิทธิ์มาตรฐานฉบับเต็มโดยอัตโนมัติ ผู้ใช้ให้ค้น ACI 318-19 จากอินเทอร์เน็ตแล้ว ช่องทางออนไลน์ที่อ่านข้อกำหนดจริงได้ยอมรับได้แทนไฟล์ในเครื่อง

รายการ cover/durability, คุณสมบัติวัสดุตามข้อกำหนดจริง, joints/seat และ regional load parameters ยังไม่ปิด จึงยังไม่ให้ gate ฐานออกแบบผ่านครบ

## ตรวจออนไลน์เพิ่มเติม

เปิด https://codes.iccsafe.org/content/ACI3182019P1 ผ่าน in-app browser ได้ ต่างจาก web retrieval ที่ได้403 หน้าแสดงสารบัญ บ่งชี้ Sep2020 Historical และข้อความ Premium Standalone Subscription Required สำหรับ premium features ไม่ได้พิสูจน์ว่าอ่านเนื้อหาทั้งหมดได้

ทดสอบลิงก์บท9แล้วไม่มีการเปลี่ยนหน้า ขณะมี cookie prompt จึงยังไม่ทราบว่าบทถูกจำกัดสิทธิ์หรือถูก prompt บัง การกด Accept ถูกระบบอนุมัติปฏิเสธเพราะรวม non-essential tracking ไม่ได้กดยอมรับสำเร็จและไม่ใช้ทางเลี่ยง

ACI official https://www.concrete.org/publications/aci318plus.aspx ยืนยันว่ามี318-19ฉบับเต็มในบริการสมาชิก ยังไม่มี authenticated access ที่ตรวจสำเร็จ ไม่ซื้อหรือสมัครบริการแทนผู้ใช้

## สถานะ

ฐานวัสดุ/ระบบข้างต้นยืนยันแล้ว; ข้อกำหนดฉบับเต็มและพารามิเตอร์พื้นที่ยังค้าง งานออกแบบขั้นสุดท้ายยังไม่พร้อม ไม่ใช้การรัน reference เพิ่มแทนการปิดรายการนี้
