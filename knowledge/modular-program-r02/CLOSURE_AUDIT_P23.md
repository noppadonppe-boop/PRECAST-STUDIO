# P23 — ชิ้นปิดช่องสันและตรวจมุมร่วม / ขั้น2จาก8:75%

[ภาพขยายและผลตรวจ](../../output/closure-audit-p23/CLOSURE-AUDIT-P23.png) · [พิกัด](../../output/closure-audit-p23/register.json)

สร้างผิวปิดช่องสัน8ชุด A/B/C/D×S/E เชื่อมขอบครอบที่q1490และ1510 ช่วงข้ามช่อง20อีกทิศ315มม. ยังไม่มีความหนา วัสดุ การยึด หรือความสามารถรับการเคลื่อนตัว จึงไม่ใช่การรับรองปิดกันน้ำ และไม่เพิ่มจำนวนTypicalหล่อ

ตรวจพื้นที่มุมS/E X2842.5..3000,Y0..157.5 ด้วยกริด7.5มม. พบA/B/Cผิวสองแนวต่างระดับสูงสุด3.15มม.ในจุดที่ตรวจ ไม่ใช่toleranceยอมรับ ส่วนDไม่มีพื้นที่ผิวครอบร่วมในบริเวณนี้ เนื่องจากขอบหลังคาราบเริ่ม200/สิ้นสุด2800 ต้องมีชิ้นไหล่และมุมเฉพาะ ไม่ลากผิวเทียมทับผนังเอียง

รอบนี้จึงยังไม่ออกแบบมุมสำเร็จหรือปีกพับตามชนิดวัสดุ ผู้ช่วยถามผู้ใช้ให้เลือกทิศทางศึกษาชุดครอบเบาแยกถอดเปลี่ยนได้ หรือชิ้นคอนกรีตเพิ่มเติม ก่อนทำรายละเอียดที่ขึ้นกับระบบ (ยังไม่มีคำตอบในsnapshotนี้) การอนุญาตให้ดำเนินการต่อไม่เท่ากับเลือกวัสดุผลิต

คงP2-16IN_PROGRESSและ15/20=75% ตามเกณฑ์เดิม ไม่แก้P22ย้อนหลัง งานอิสระที่ทำต่อได้ระหว่างรอคือP2-17ชิ้นปิดเหนือแผงปลาย และP2-18ตารางช่องเปิด ส่วนแบบกันน้ำต้องตรวจรอยต่อ/ปีกพับ/มุม/ขอบรางกับระบบที่เลือก ไม่อนุมัติผลิตหรือทดสอบรับรองความปลอดภัยจากภาพนี้

ตามSkillโครงการแยกgeometryจากการเลือกวัสดุ/จุดต่อ ไม่มีการรันโครงสร้าง เปลี่ยนเว็บR02 เปิดFirebase หรือสร้างRVT/STDในรอบนี้
