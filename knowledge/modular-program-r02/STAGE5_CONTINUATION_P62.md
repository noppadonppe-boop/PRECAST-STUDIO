# P62 — โครงยึดบล็อกหน้าต่าง A/B/D ซ้าย–ขวา

ขั้น5/8 ต่อจากP61 งานออกแบบระบบย่อยตามP40 ไม่เพิ่มcoverageแม่แบบเต็มชุด ไม่เริ่มขั้น6

## รายละเอียดที่เพิ่มจริง

- 6รุ่น A/B/D × LH/RH-W01 ใช้รูปคอนกรีตและcasting transformต้นทางเดิม ไม่เปลี่ยนTypicalหรือช่องเปิด
- WCเป็นชุดเชื่อม12stock pieces: แผ่นธรณี/หัวช่อง6mm, เสาในช่อง SHS50×50×4 สองต้น, เสานอก SHS100×100×6 สองต้น, แขน RHS100ลึก×50×5 ยาว400mm สี่ชิ้น, เพลตฐาน200×200×20 สองแผ่น
- 8สกรูฐาน nominalM20 / clearance22ในเพลต / ที่นั่งเกลียวnominal20ลึก25ในฐาน30 พร้อมwasher22ID40OD3. ไม่ใช่tap-drill dimensionหรือการตรวจเกลียวตามcode
- แบบDวางโครงในแกนตั้งฉาก–ตามแนวผนังเอียง ไม่shearหน้าตัดเหล็กให้ผิดรูป; RHเป็นรูปสะท้อนจริงของLH
- ผิวM01นอกต้องเจาะช่องตามvoidหน้าต่างเพื่อให้โครงWCลอดออกได้. negative testแสดงว่าผิวเดิมชนโครงใหม่ ไม่เพียงยกภาพออกมาลอยๆ
- น้ำหนักstockของWCประมาณ96.202kg A/B และ96.244kg D ยังไม่รวมweld/seal/rigging อุปกรณ์เพิ่ม

## ตรวจและผลแรง

13testsผ่าน: ตรงsourcegeometry, ไม่ชนในท่าประกอบ, 35ช่วงการเคลื่อนต่อชุดรวมสกรู/แหวน, 8socket envelopesØ48, stockไม่ทับกัน, mass/CGสะท้อน, negative controlsสำหรับรูฐาน/ช่องถอน และผลแรงบันทึกแยกจากcapacity

ผลแรงstaticเฉพาะธรณี+หัวช่อง+น้ำหนักWC: แรงยกสุทธิประมาณ3.10658kN A/B และ3.11630kN D. แรงลัพธ์นี้มีโมเมนต์เยื้องศูนย์เทียบกลุ่มรูฐานประมาณ1.75kN.mในองค์ประกอบหลัก จึงห้ามหารแรงสุทธิ8เพื่อถือเป็นแรงสกรูเท่ากัน. JSONเก็บoriginและsignครบ แต่individual bolt force/capacityยังnull/false

ฐานแรงคงfull hydrostatic25kN/m³/head1485 ไม่เพิ่มfactorเอง. คู่มือเครื่องมือ [PERI Formwork Load Calculator](https://apps.peri.com/SLR/index.php?lang=en&norm=aci) แยกสมมติฐานแรงดัน/มาตรฐานและข้อมูลกำลังของระบบจริง จึงไม่ใช้ค่าระบบสำเร็จรูปนั้นมาเป็นcapacityของแม่แบบcustomนี้. ไม่มีการกล่าวอ้างว่าP62ผ่านDIN/ACI/วสท.

## การถอดและข้อจำกัดที่ยังต้องปิด

โมเดลตรวจการถอนสกรู+แหวนก่อน, ถอยside insertsตามแนวผนังแล้วออกด้านนอก, ถอนWC±800Xแล้ว+1800Z ก่อนถอนผนังนอกและผิวอื่น. เป็นclearance sequence ไม่ใช่แผนปฏิบัติการยกที่อนุมัติ ต้องมีtemporary capture/supportที่ออกแบบก่อนปลดสกรู ไม่อ้างว่าชุดตั้งเองระหว่างถอน

Side-insert locks/support, welds, seal/tolerance, handling support, main wall/roof ribs/frames/locksและstrength checksยังคงเป็นงานที่ต้องปิดในขั้น5 ไม่ตัดออก. ขนาดเหล็กในเอกสารนี้เป็นเหล็กแม่แบบ ไม่ใช่ขนาดเหล็กเสริมคอนกรีต; แนวเหล็กคอนกรีตคงP52และไม่ใส่ขนาด
