# P104 — อนุมัติขยายขั้น6.1 อีก47แบบ

ผู้ใช้ตรวจรับตัวอย่าง PM-I-B3/P103 และอนุมัติให้ขยายอีก47แบบตามขั้น6.1 เมื่อ18กันยายน2026 ข้อจำกัดรออนุมัติ47แบบในP103เป็นประวัติแล้ว

## ขอบเขตคงเดิม

48แบบ = I/L/U × A/B/C/D × ออฟฟิศ/บ้านพัก/ร้านกาแฟ/รีสอร์ท คงตัวอย่าง I-B3 ที่ตรวจรับ แยก47ชุดใหม่ ไม่เขียนทับต้นฉบับP103หรือโครงสร้างP6/P36

แต่ละแบบต้องเป็นARC RVT2026แยกและLinkโครงสร้างเดิม พร้อมไฟล์อ้างอิง/Familyที่ใช้, แบบA1, ภาพจากRevitจริง, รายการวัสดุไม่ผูกยี่ห้อ, รายการเฟอร์นิเจอร์/ช่องเปิด/ตำแหน่งแอร์–ไฟฟ้า–สุขาภิบาล, README/QA/ZIP ใช้มาตรฐานตัวอย่างP103 ไม่คัดลอกร้านกาแฟไปใส่ทุกการใช้งาน

ปรับเฟอร์นิเจอร์/ตำแหน่งMEP/ผิวสำเร็จตามผังและช่องเปิดP36ของแบบนั้น คงคอนกรีตทุกชิ้นและความหนาเดิม ไม่สร้างรูเจาะใหม่ ห้องน้ำที่มีพื้นที่สำรองให้พัฒนาผนังเบาและสุขภัณฑ์ขั้นต้น ส่วนIออฟฟิศ/คาเฟ่ยังใช้ห้องน้ำภายนอกตามต้นทาง

Revitต้องแก้ไขต่อได้ด้วยNative Floor/Wall/Loadable Families พร้อมแจ้งข้อจำกัดparametricและnon-hosted openings ใช้ภาพจริงจากโมเดลและตรวจความสัมพันธ์ARC/STR ไม่ใช่แค่ภาพสวย

## วิธีนับและตรวจ

- งานเสร็จรายแบบต้องครบ: model/reference + native reopen + structure fingerprint + opening/geometry coordination + sheets/images + specs/schedules + relocation/ZIP verification + visual review
- รายงานจำนวนแบบครบจาก48เป็นเปอร์เซ็นต์หลัก ไม่เรียกการเตรียมสูตรหรือ生成ไฟล์อย่างเดียวว่าเสร็จ
- ก่อนเริ่มขยาย: แบบตรวจรับ1/48 =2.08%; ใหม่0/47
- เก็บรายงานขั้นระหว่างทำแยกจากจำนวนชุดส่งมอบจริง
- ข้อผิดพลาดการชนและLinkต้องแก้และรันใหม่; ไม่ลบรายการที่ไม่ผ่านเพื่อให้ผลดูครบ
- เพิ่มชุดARCในคลังข้อมูลแยกประเภทจากStructural เมื่อไฟล์ผ่านตรวจ โดยรักษาภาพเดิมและสิทธิ์ภายในทีม

## ขอบเขตที่ไม่เพิ่ม

ไม่มีการคำนวณMEP/ออกแบบขนาดระบบ/กำลังจุดยึด/ฐานระเบียงหรือการตรวจมาตรฐานอาคารครบถ้วนในรอบนี้ ไม่เริ่มSTAADขั้น7 ไม่เปิดสาธารณะหรือFirebase ไม่ถือการตรวจรับงานพัฒนาเป็นengineering approval/production release

จบชุด48เมื่อหลักฐานครบแล้วหยุดรอผู้ใช้ตรวจ ไม่ต้องถามอนุมัติซ้ำทุกแบบระหว่างทำ
