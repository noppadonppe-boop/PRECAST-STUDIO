# I-C1 P04 — ผังสำนักงานและชุดปิดปลายเสนอ

[ภาพ PNG](../../output/ic1-layout-p04/I-C1-P04.png) · [ข้อมูลโมเดล](../../output/ic1-layout-p04/assembly.json)

คง P03 เป็นประวัติ เพิ่มผัง2ที่นั่ง ตู้เอกสารและแผงปิดปลายด้านหน้า/หลังภายในกรอบ3×6ม.
โต๊ะ1200×600 สูง750จากพื้นโครงสร้าง; ตำแหน่งไม่บังช่องหน้าต่างทางเรขาคณิต แต่การเปิดบานจริงยังไม่ได้เลือก
ทางเดินเสนอ1100 ไม่ซ้อนพื้นที่ใช้เก้าอี้ที่กำหนด; ไม่ถือว่าตรวจการเข้าถึง/ทางหนีไฟตามกฎหมายแล้ว

EP-D01 หน้าและ EP-S01 หลัง: หนา150 ขนาด2660×2325มม.จากZ175ถึง2500; แผงหน้าเจาะช่อง1000×2100มม.
ช่องประตูคอนกรีตไม่ใช่ความกว้างผ่านสุทธิ; กรอบประตู วิธีเปิด พื้นหน้าทางเข้า ระดับไซต์ และ threshold ยังไม่สรุป
เหนือแผงยังมีพื้นที่เติมถึงใต้โค้ง ต้องพัฒนาชุด infill วัสดุ/กันน้ำ/การยึด; ภาพเส้นประไม่ใช่แผงที่ออกแบบแล้ว
14แผงที่ระบุ =12แผงเดิม+2ปิดปลาย ยังไม่ใช่BOMครบหลังและยังไม่เลือกฐานรองแผงปลาย
ผังเสนอไม่มีห้องน้ำภายใน ต้องยืนยันการใช้ห้องน้ำภายนอก/ส่วนกลางก่อน freeze แบบ; MEPยังไม่ได้ออกแบบ

ตรวจข้อมูลและเรขาคณิตเพิ่ม5ชุด: ตำแหน่งแผงปลาย ช่องประตู เฟอร์นิเจอร์ไม่ชน ทางเดินไม่ถูกกีดขวาง และสถานะยังไม่อนุมัติ รวม23testsผ่าน
ตรวจ PNG แล้ว; แบบยังไม่เชื่อมเว็บ ไม่สร้างRVT/STD และไม่รันโครงสร้าง
