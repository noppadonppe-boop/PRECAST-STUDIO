# P86 — การดัดแผ่นขาฐานเหล็กและแรงสลัก P85

ขั้น5/8 ยังไม่ครบ100%. ขอบเขตรอบนี้คือ24กลุ่มขาฐานของ6setup A/B/D–LH/RH–W01 ไม่ใช่แม่แบบ44setupครบกำลัง และไม่ใช่การคำนวณคอนกรีตอาคารขั้น7

## Geometry และกรณีแรง

คงแผ่นขาฐานเหล็ก350×200×30mm และรูจริง nominal Ø22 จาก P85. ไม่เปลี่ยนความหนาคอนกรีต Typical. ใช้ ShellMITC4 ของ OpenSeesPy runtime3.8.0, E200000MPa, nu0.3, ฐานสัมผัสรับแรงกดฝ่ายเดียว kc1000N/mm³ และสลักรับแรงดึงฝ่ายเดียว k=E×245/50N/mm. ค่า245mm²และความยาวยืดตัว50mmเป็นกรณีศึกษา ไม่ใช่ใบรับรองสลัก

แหวนใช้บริเวณ rigid patch รัศมี20mm ไม่ใช่ผลตรวจความแข็งหรือกำลังแหวนจริง. DOFในระนาบแผ่นถูกตรึงเพื่อศึกษาการดัด; ไม่ใช้โมเดลนี้คำนวณแรงเฉือนของกลุ่มสลัก

กลับทิศแรงรองรับจาก P83 ไปยังขาฐานและเลื่อนจุดอ้างอิงถึงฐาน z0 โดยเก็บแรงดิ่ง/Mx/My ครบ. แมปลง nodeวัสดุที่ใกล้ที่สุดพร้อมแก้คู่โมเมนต์ให้รักษา wrench. โหลดจุด/คู่โมเมนต์ทำให้เกิดยอดความเค้นเฉพาะที่ จึงไม่ใช้ peak Gauss stress รับรองกำลัง

เป็น hydrostatic-pressure case เดิมของ P83 เท่านั้น ไม่รวม gravity, handling หรือ load combinations และเป็นการส่งแรงทางเดียวจากผนังฐานแข็งเกร็ง ไม่ได้คืนความยืดหยุ่นขาฐานเข้าแบบจำลองผนังทั้งชุด

ข้อมูล `gaussResultants` ดิบเก็บไว้สอบย้อนกลับ ไม่ใช่ตารางออกแบบที่ยืนยันแกน/องค์ประกอบและเกณฑ์ประเมินความเค้นแล้ว. ภาพรอบนี้แสดงการกระจัดและแรงสลักเท่านั้น. ตรวจ hash ของ inputs เทียบ manifest ชุดส่งมอบ P83/P85เดิมเพิ่มเติมจากการตรวจไฟล์ปัจจุบัน

## การตรวจตัวแบบ

- ตาข่ายรักษารู32เหลี่ยมและพื้นที่หน้าตัดจริง ตรวจ free edges ไม่ให้เกิดรอยแยกภายใน และตรวจ Jacobian ทุกจุดอินทิเกรต
- ตรวจสมดุลแรง/โมเมนต์รวม, residual ของ DOFอิสระหลังรวมแรง MPC และการเข้ากันได้ของการเคลื่อนตัวแหวน–แผ่น ไม่ใช้ solver exit อย่างเดียว
- ทดสอบสปริงแรงกด/แรงดึงกับคำตอบตรง และ rigid-offset beam กับคำตอบ0.00099mm
- พบวิธีเพิ่มโหลด10ขั้นของ runtime/การตั้ง constraints นี้ให้ slave displacement ไม่เข้ากัน แม้สมดุลปิดได้ จึงตัดผลวิธีนั้นออก. ผลที่เก็บใช้งานรันใหม่แบบหนึ่งขั้นและตรวจ MPC ทุกไฟล์. ไม่สรุปว่า OpenSees ทุกโมเดลมีปัญหาเดียวกัน
- เทียบแผ่นบาง simply-supported รับ sinusoidal load กับคำตอบ Kirchhoff: กริด32×32คลาดเคลื่อน0.2664%, ต่ำกว่าเกณฑ์1%. ความคลาดเคลื่อนสามกริดไม่ได้ลดแบบ monotonic จึงเรียกเพียง bending-scale benchmark ไม่ใช่ stress-convergence
- เพิ่มความแข็งหน้าตัดเทียบ rigid-foot answer ด้วย section300mm เป็น **rigid-limit probeเท่านั้น** ไม่ใช่การเสนอเหล็กหนา300mmหรือเปลี่ยน geometry30mm

## เกณฑ์และผล refinement

A-LH-M01-F1 เริ่มเป็น exploratory pilot. บันทึกเกณฑ์ก่อนขยายชุด: เวกเตอร์แรงสลักและ max uplift ต่างไม่เกิน2%; สมดุล0.01N/1Nmm; MPC1e-8mm; residual DOFอิสระ0.01N/1Nmm

ชุดหลัก24กลุ่มใช้กริดเป้าหมาย20/10mm. เมื่อ Dไม่ผ่านเกณฑ์ uplift จึงเพิ่มทุก8กลุ่ม Dเป็น7.5mm เปรียบเทียบ10→7.5 โดยไม่ผ่อนเกณฑ์2% และเก็บผล20/10เดิม. ไม่กล่าวว่า meshเป้าหมายเท่ากับความยาวขอบทุกelement เพราะเป็นการแบ่ง polygonsรอบรูจริง

ผลส่งมอบและจำนวนที่ตรวจจริงต้องอ้าง [audit.json](../../output/foot-flex-p86/audit.json), [ตารางแรง](../../output/foot-flex-p86/summary.csv) และ [ภาพรายงาน](../../output/foot-flex-p86/index.html). เกณฑ์นี้ตรวจเฉพาะแรงสลัก/การยกตัว ไม่รับรอง stress singularities หรือกำลังแม่แบบ

ตรวจครบ56ไฟล์ผลคำนวณ: ผ่าน refinement24/24กลุ่ม =100%เฉพาะงานย่อยนี้, symmetry12/12คู่ และ automated tests31ข้อ. แรงดึงสูงสุด41.240kN/สลัก; max uplift0.22360mm ในกรณีศึกษาที่ระบุ ไม่ใช่กำลังรับได้. Rigid-limit probeคลาดเคลื่อนเวกเตอร์แรงสลัก0.1762% เทียบคำตอบ rigid contact. ชุดภาพ24แผ่นสร้างจากผลโดยตรง ไม่ใช้AIสร้างสนามการกระจัด

## งานต่อในขั้น5

ใช้แรงที่รวมการดัดแผ่นนี้ทบทวน plate/washer/bolt/thread/weld และรวมความยืดหยุ่นกับโครงผนัง–หลังคา–หัวท้ายตามขอบเขต. ยังต้องปิด supported handling, lifting/rotation, ฐาน, tolerance/seals และแบบผลิต/QCครบ44setup ตามP40. ไม่เริ่มขั้น6 และไม่แก้สถานะอนุมัติผลิต

P52คงเดิม: เสนอแนวเหล็กยกคอนกรีตไม่ใส่ขนาด สมมติกำลังพอเฉพาะพัฒนาแบบ ไม่ขอข้อมูลเดิมซ้ำ และไม่ยกสมมตินี้ไปใช้รับรองระบบยกเหล็ก/พุก/สลิง/พื้นโรงงาน
