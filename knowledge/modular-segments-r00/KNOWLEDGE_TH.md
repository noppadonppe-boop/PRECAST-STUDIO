# Modular Product & Segment Knowledge — R00

วันที่ 16 กันยายน 2026 · โครงการ Precast-Module  
สถานะ **PROPOSED CONCEPT / NOT FOR CONSTRUCTION / NOT RELEASED FOR MOULD FABRICATION**

## 1. สิ่งที่บันทึกจากผู้ใช้ และสิ่งที่เสนอเพิ่ม

**โจทย์ที่ผู้ใช้กำหนด:** 16 ภาพเดิมเรียก Type I; เพิ่ม Type L 27 ตร.ม. และ Type U 45 ตร.ม. อย่างละ 16 แบบ; เก็บ Knowledge และบัญชี Typical Segment พร้อม Tag สำหรับพัฒนาแม่แบบในอนาคต

**ข้อเสนอ R00 ของผู้ช่วย ซึ่งยังไม่ใช่การอนุมัติผลิต:** ใช้ระยะช่วง 1.50 ม. สำหรับ L/U; เสนอสูตร I-STD15 สำหรับอนาคต; ใช้ชุดเชื่อมมุม N90 แยกจากซีกตรง; ลดรูปหน้าตัดของ L/U ให้เหลือ P00 หนึ่งรูปต่อครอบครัว A–D เพื่อลดความแตกต่างของแม่แบบ

ห้ามอ้างว่าผู้ใช้ได้อนุมัติความหนา กำลังคอนกรีต เหล็ก/ลวดอัดแรง จุดต่อ หรือเครื่องมือแบบหล่อแล้ว เอกสารนี้ไม่เลือกใช้คอนกรีต 320 ksc หรือระบบ prestress โดยอัตโนมัติจากบทสนทนาเก่า

## 2. ระบบชื่อแบบอาคาร 48 แบบ

- Type I = แปลนตรง 3×6 ม. พื้นที่กรอบโมดูล 18 ตร.ม.
- Type L = กรอบ 6×6 ม. เว้นมุม 3×3 ม.; พื้นที่ 36−9 = 27 ตร.ม.
- Type U = ปีกซ้าย 3×6 + ปีกขวา 3×6 + สะพานหลังกลาง 3×3; พื้นที่ 18+18+9 = 45 ตร.ม.; กรอบรวม 9×6 ม. คอร์ตหน้ากลาง 3×3 ม.
- ตัวอักษร A = จั่ว, B = โค้งต่อเนื่อง, C = โค้งเฉพาะมุมหลังคา–ผนัง, D = หน้าตัดคางหมู
- หมายเลข 1 = ออฟฟิศ, 2 = บ้านพัก, 3 = ร้านกาแฟ, 4 = รีสอร์ต
- ตัวอย่าง Building Tag: **PM-L-C3-R00** = Type L / ครอบครัวมุมโค้ง / ร้านกาแฟ / Revision 00
- [ทะเบียน 48 แบบ](variant_register.json) เชื่อมกลับไปยังภาพจริง; 32 แบบ L/U ใหม่แยกจาก 16 แบบ I เดิม ไม่เขียนทับภาพเดิม

พื้นที่เป็น **พื้นที่กรอบประสานโมดูลภายนอกแบบนามบัญญัติ** ไม่ใช่พื้นที่สุทธิใช้สอยหรือพื้นที่ตามกฎหมายที่รับรองแล้ว ไม่รวมระเบียง คอร์ต หรือชายคา ต้องหักความหนาผนัง/งานตกแต่งและตรวจการนับพื้นที่ตามสถานที่จริงในขั้นออกแบบ

## 3. Geometry และความยาวมาตรฐาน

### รักษา Type I เดิม

ภาพเดิมใช้ 3 ช่วง × 2.00 ม. = 6.00 ม.; มีซีกผนัง–หลังคา 6 ชิ้น + พื้น 3 ชิ้น รหัสรุ่น **I-LEGACY20** ใช้โปรไฟล์ LEG-A1 … LEG-D4 เพราะภาพเดิมต่างสัดส่วนกันตามการใช้งาน ห้ามถือว่าทุกภาพในครอบครัวใช้แม่แบบเดียวกันได้แล้ว

ทะเบียนสงวนรหัสชิ้นเดิมเป็น PC-{A..D}-LEG{1..4}-H20-{LH|RH}-{opening}-R00; พื้น PC-X-F20-3000x2000-LEG-R00. ขนาดหน้าตัด/ตำแหน่งช่องต้องตรวจแบบ CAD ใหม่ก่อนสร้างรายการผลิตจริง

### มาตรฐานเสนอใหม่ STANDARD15

- 1.50 ม. หารทั้ง 3.00 และ 6.00 ม. ลงตัว อยู่ในช่วง 1.5–2 ม. ที่ผู้ใช้เคยระบุ
- 1 ช่วงตรง 3.00×1.50 ม. = ซีก H15-LH + ซีก H15-RH + พื้น F15
- 1 เซลล์ตรง 3.00×3.00 ม. = 2 ช่วงตรง = 4 ซีก + 2 พื้น
- I-STD15 เสนอเป็นทางเลือกในอนาคต: 4 ช่วงตรง = 8 ซีก + 4 พื้น; **ยังไม่ได้สร้างภาพ I ใหม่ และไม่เปลี่ยนจำนวนชิ้นในภาพเดิม**
- แบบ L/U ใช้ P00 เดียวกันภายในแต่ละครอบครัว แม้เปลี่ยนฟังก์ชันและการตกแต่ง ภาพ AI อาจคลาดสัดส่วน; ข้อมูล Catalog เป็นเจตนาอ้างอิงสำหรับทำ CAD ต่อ

| Profile เสนอ | ฐานกว้าง | สูงภายนอกรวม | รูปทรงตั้งต้น |
|---|---:|---:|---|
| PF-A-P00-R00 | 3.00 ม. | 3.00 ม. | ผนังตั้งถึง 2.35 ม. แล้วหลังคาจั่ว |
| PF-B-P00-R00 | 3.00 ม. | 3.00 ม. | ผนังตั้งประมาณ 1.90 ม. แล้วโค้งวงรีต่อเนื่อง |
| PF-C-P00-R00 | 3.00 ม. | 3.00 ม. | ผนังตั้ง บ่ามุมโค้งประมาณ R0.40 ม. กลางหลังคาเกือบราบ |
| PF-D-P00-R00 | 3.00 ม. | 3.00 ม. | ผนังเอียงเข้า หลังคากว้าง 2.60 ม. เกือบราบ |

ตัวเลขระดับ/รัศมีเป็นกรอบสถาปัตย์เริ่มศึกษา ไม่ใช่ค่าที่ผ่านการออกแบบโครงสร้าง ชั้นกันซึมและความลาดระบายต้องพัฒนาต่อ

## 4. Typical Segment และหลักการแบ่งชิ้น

### H15: ชิ้นตรงหลัก

ซีกหนึ่งประกอบด้วยผนังด้านเดียวและครึ่งหลังคาที่หล่อเป็นชิ้นเดียวกัน แยกซ้าย–ขวาตามระนาบดิ่งกลางหลังคา; ความยาวตามแกนอาคาร 1.50 ม. ไม่ใช่การแบ่งหลังคาออกจากผนังแนวนอน พื้น F15 แยกหล่อ แต่ยังต้องออกแบบการยึด/การถ่ายแรงร่วมกัน

คำว่า LH/RH ให้มองตาม **แกน +s ของเซลล์ใน placement_grid** จากหน้าตัดต้นไปท้าย ไม่เปลี่ยนชื่อชิ้นตามมุมกล้องภาพหรือทิศเหนือ ส่วน X/Y คือทิศวางในโครงการ ไม่ใช่รหัสแม่แบบอีกชนิด

### N90: ชุดเชื่อมมุม 3×3 ม.

**N90 เป็นชุดประกอบ ไม่ใช่ชิ้นหล่อหนึ่งชิ้น และไม่ใช่ H15 ธรรมดา**

- มีสองหน้าติดกันเป็นช่องเชื่อมภายใน 90° อีกสองหน้าเป็นผนังภายนอก
- เสนอหลังคาเชื่อมคอนกรีตค่อนข้างราบระดับภายนอกประมาณ 2.70 ม. แยกจากหลังคาปีก 3.00 ม.; ต้องตรวจระยะยืนสุทธิ/การชนหลังคา/การกันซึม
- บัญชีแผงตั้งต้นต่อ 1 ชุด: แผงหลังคา NR15 ขนาดนามบัญญัติ 3×1.5 ม. 2 ชิ้น + แผงผนัง NW15 กว้าง 1.5 ม. 4 ชิ้นบนสองหน้าภายนอก
- พื้นของโหนด 2 แผง F15 **นับในยอดพื้นรวมอาคารแล้ว** ห้ามบวกซ้ำ
- คานขอบ กรอบช่องเชื่อม อุปกรณ์ยึด และโครงรองรับ: **จำนวน/หน้าตัด TBD** ต้องวิเคราะห์; รายการแผงข้างต้นไม่ใช่ BOM โครงสร้างครบชุด
- ชุดปลอกเปลี่ยนหน้าตัด TR ใช้เชื่อมปีกกับ N90 สองชุดต่อ N90; รูปร่างต่างกันตาม A–D จึงไม่รับรองว่าชุด TR แลกใช้ข้ามครอบครัวได้
- ต้องไม่ตัดผนัง H15 ทึบหน้างานเพื่อสร้างช่องเชื่อมโดยไม่มีการออกแบบ
- รูปหลังคา N90 ราบเป็นข้อยกเว้นที่ตั้งใจใช้กับจุดเลี้ยว; ผนัง–หลังคารวมชิ้นแบบ H15 ยังคงใช้กับช่วงตรง

การแยก N90 ออกมาช่วยทำบัญชีและกำหนดงานพัฒนารอยต่ออย่างตรงไปตรงมา **ไม่ได้พิสูจน์ว่าเป็นทางเลือกที่ถูกที่สุดหรือแข็งแรงที่สุด**

## 5. บัญชีระดับโมดูลและแผง

| รายการ | I เดิม 2 ม. | I-STD15 เสนอ | L 27 ตร.ม. | U 45 ตร.ม. |
|---|---:|---:|---:|---:|
| ช่วงตรง | 3 | 4 | 4 | 6 |
| ซีกผนัง–หลังคาตรง | 6 H20 | 8 H15 | 8 H15 | 12 H15 |
| N90 (ชุด ไม่ใช่ชิ้น) | 0 | 0 | 1 | 2 |
| พื้นรวม รวมพื้นโหนดแล้ว | 3 F20 | 4 F15 | 6 F15 | 10 F15 |
| แผงหลังคาโหนด NR15 | 0 | 0 | 2 | 4 |
| แผงผนังโหนด NW15 | 0 | 0 | 4 | 8 |
| TR interface (ชุดเสนอ) | 0 | 0 | 2 | 4 |
| ชุดปิดปลายปีก | 2 | 2 | 2 | 2 |
| กรอบ/คานขอบ/อุปกรณ์ยึด | TBD | TBD | TBD | TBD |

จำนวนแผงหลักที่ระบุได้ตามข้อเสนอคือ L = 8+6+2+4 = 20 แผง และ U = 12+10+4+8 = 34 แผง **ไม่ใช่ยอดชิ้นงานผลิตทั้งหมด** เพราะยังไม่รวมรายการ TBD, TR, ชุดปิดปลาย, ฐาน และงานระบบ

บัญชีนี้เป็นสูตรวางโมดูลตามกริด ไม่ใช่การถอดปริมาณจากภาพ AI; จำนวน W01/D01/H01/V01 และผนังทึบต้องเลือกจาก Opening Schedule ของแต่ละแบบที่จัดทำ CAD แล้ว ห้ามนำชนิดช่องเปิดทั้งหมดใน Catalog มารวมเป็นจำนวนที่ต้องผลิต

## 8. แนวทางทำแม่แบบในอนาคต

R00 ตั้งเป้าจัดกลุ่ม shell mold envelope 4 ครอบครัว × 2 ซีก = **8 ชนิดหลักเชิงแนวคิด** สำหรับ H15-P00 ไม่รวม legacy H20, insert, แบบ F15/NW15/NR15, TR, node supports, ผิวตกแต่ง และความแตกต่างจากผลคำนวณ

ยังไม่รับรองว่าจะใช้เครื่องมือจริงเพียง 8 ชุด หรือใช้แบบ LH พลิกเป็น RH ได้ ให้สำรวจรูปแบบถอดแม่แบบ มุม draft ขอบรอยต่อ ตำแหน่งฝังชิ้นส่วนและช่องเปิดก่อน ต้องแยก tooling revision ออกจาก part/design revision และบันทึกความเข้ากันได้

ลำดับข้อมูลก่อนปล่อยทำแม่แบบ:

1. กำหนด Design Basis และขนาดสุทธิใช้สอยของแบบเป้าหมาย
2. สร้าง CAD/BIM geometry ที่แน่นอน: พื้นผิว แกนอ้างอิง ระบบพิกัด ความหนา ช่องเปิด รอยต่อ และ tolerance
3. วิเคราะห์โครงสร้างทั้งใช้งาน ยก ขนส่ง ประกอบ ลม แรงด้านข้าง และโหนด; ระบุแรงที่แต่ละ interface ต้องถ่าย
4. ออกแบบวัสดุ เหล็ก จุดยก จุดต่อ และแผนค้ำยัน พร้อมตรวจโดยผู้รับผิดชอบ
5. ตรวจแนวทางถอดแบบ ลำดับหล่อ บ่ม และเกณฑ์ทดสอบต้นแบบ
6. อนุมัติ shop drawing + mold drawing + QC/ITP ที่ผูก revision เดียวกัน
7. ผลิตชิ้นทดลอง ทดลองประกอบ/ตรวจรอยต่อและการกันน้ำ แล้วจึงพิจารณา release

ทุกเกตใน R00 ยังเป็น **NOT STARTED / NOT APPROVED** ไม่อนุมานว่า Knowledge หรือภาพสวยคือผ่าน gate แล้ว

## 9. ขอบเขตความปลอดภัยและความถูกต้อง

- รูปทรงโค้งไม่ได้รับประกันความบาง/น้ำหนักต่ำเมื่อมีช่องเปิดและรอยต่อ; ต้องตรวจเสถียรภาพและแรงถ่าง
- การเปลี่ยนจากชิ้นเต็มเป็นซีกหรือการเพิ่ม N90 เปลี่ยนทางถ่ายแรง ไม่ใช้ผลออกแบบของชิ้นเดิมโดยอัตโนมัติ
- AI board อาจมีสัดส่วน/ตัวเลข/จำนวนชิ้นในภาพย่อยคลาดเคลื่อน ใช้ Catalog และ placement grid เป็น **ข้อกำหนดเจตนา** และทำ CAD ใหม่ ไม่วัดจากพิกเซล
- ภาพ exploded ไม่ใช่ขั้นตอนยกจริงหรือการรับรองว่าซีกตั้งเองได้
- พื้นกว้าง 3 ม. ยังต้องตรวจรถ การจัดวางและข้อกำหนดขนส่งตามเส้นทางจริง; การแบ่งซีกหลังคาไม่ได้แก้ข้อจำกัดขนส่งของพื้นทั้งหมด
- หลังคาโหนด รอยต่อมุม และจุดเปลี่ยนระดับต้องพัฒนากันซึม/ระบายน้ำ/ฉนวน ไม่แก้ด้วยยาแนวอย่างเดียว
- ตรวจความสูงสุทธิ ทางเดิน ห้องน้ำ ประตู การเข้าถึง ทางหนีไฟและข้อกำหนดอาคารตามสถานที่จริง; ภาพเฟอร์นิเจอร์ไม่ใช่หลักฐานระยะใช้งาน

กรอบอ้างอิงด้านเปลือกคอนกรีต: [ACI PRC-334.1-22 — บทนำและสารบัญ](https://www.concrete.org/Portals/0/Files/PDF/Previews/334.1-22_preview.pdf) กล่าวถึงการวิเคราะห์ ออกแบบ เสถียรภาพ รอยต่อ และก่อสร้าง เป็นแนวทางให้วิศวกรศึกษา ไม่รับรองผลิตภัณฑ์หรือข้อเสนอ N90 นี้
