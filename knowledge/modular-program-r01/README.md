## ลำดับความสำคัญของข้อมูล

คำสั่งล่าสุดของผู้ใช้ > ข้อตกลง R01 ฉบับนี้ > เอกสาร/ข้อมูลแนวคิด R00 > ภาพประกอบ
ลำดับนี้ใช้กับเจตนาผลิตภัณฑ์ ไม่อนุญาตข้ามการตรวจมาตรฐานหรือการอนุมัติวิศวกรรม

R01 แทนเฉพาะสถานะข้อเสนอเดิมเรื่องช่วง1.50ม.ร่วมกัน การเลือกTS-Cนำร่อง ความหนาเป้าหมาย และการเปิดเผยข้อมูล; ไม่เปลี่ยนผลตรวจหรือภาพR00ย้อนหลัง และไม่รับรองรูปทรง/วัสดุ/จุดต่อที่ยังไม่ออกแบบ

R00ต้นทางอยู่ที่ [modular-segments-r00](../modular-segments-r00/KNOWLEDGE_TH.md) ส่วนสำเนาใต้ Picture Stock และ ZIP เป็น snapshot ประวัติ ไม่ใช่แหล่งข้อมูลสดสำหรับแก้ไข

## Snapshot กับความคืบหน้าในอนาคต

หลังส่งมอบครั้งนี้ `baseline.json`, `product_matrix.json` และเอกสาร R01 เป็น initial planning snapshot ไม่ใช่ฐานสถานะงานสด ค่าความหนา null และ NOT_ANALYSED บันทึกสิ่งที่ทราบ ณ วันที่ล็อกแผน
เมื่อเริ่มวิเคราะห์/ออกแบบ ให้สร้าง design revision และ live artifact records แยกโดยอ้างอิง snapshot นี้ ไม่แก้สถานะย้อนหลังและไม่ให้ภาพเก่าเปลี่ยนความหมาย
`validate.mjs` ตรวจความถูกต้องของ snapshot R01 เท่านั้น จึงตั้งใจคาดหวัง null/NOT_ANALYSED; งาน revision ใหม่ต้องมี validation ตาม lifecycle ของมัน ไม่ลดเกณฑ์ R01 เพื่อให้ผลใหม่ผ่าน
