## 4. ลำดับนำร่อง

เลขStepของแผนนี้ไม่ใช่เลขGateของแอปเดิม: G0=BIM accepted, G1=Design Basis approved, G2=Analytical model ready, G3=Analysis verified, G4=Design approved, G5=BOQ/estimate reviewed, G6=Drawing ready, G7=Production released
Step0เตรียมG0/G1ตามข้อมูลที่เกี่ยวข้อง; Step1เว็บไม่มีสิทธิ์อนุมัติengineering gate; Step2ผ่านG2/G3เมื่อหลักฐานครบ; Step3สัมพันธ์G4; Step4สัมพันธ์G6และต้องผ่านเงื่อนไขreleaseก่อนG7; Step5อ้างอิงrevisionที่ผ่านgateและทบทวนG0เมื่อเปลี่ยนBIM input
G5เป็นงานBOQ/ราคาในระบบเดิมซึ่งไม่ได้เพิ่มเป็นงานคำนวณราคาในขอบเขตครั้งนี้ หากworkflowผลิตจริงต้องใช้G5ให้จัดงานตามpolicyเดิม ไม่ข้ามหรืออ้างว่าผ่านแล้ว

TS-C half-shell LH/RH + F15 → หนึ่งbay → I-C1-STD15 → N90/TR → L-C1/U-C1 → ช่องเปิด/การใช้งานอื่นของC → A/B/D
I-C1เป็นข้อเสนอจัดลำดับจากผู้ช่วย; การยืนยันTS-Cจากผู้ใช้ไม่ได้อนุมัติรายละเอียดช่องเปิด/แปลนหรือวัสดุของI-C1
เว็บสามารถจัด48ช่องรายการได้ตั้งแต่Step1 แม้ผลวิศวกรรมยังมีเฉพาะชุดนำร่อง

## 5. Change control

- เปลี่ยนความหนาเฉพาะชิ้น: บันทึกเหตุผล กรณีแรงที่คุม ผลต่อมวล/ความแข็ง/ช่องใช้สอย/รอยต่อ/แม่แบบ และผู้ตรวจ
- แยก product revision, geometry revision, material case, analysis run, part design และtooling revision
- ความหนาไม่จำเป็นต้องฝังในTagเดิมทุกครั้ง แต่ต้องอยู่ในdesign recordที่immutable; ชิ้นที่เข้ากันไม่ได้ต้องแยกvariant/interface compatibility
- ถ้าแก้โหลด/BC/geometry/material/ความหนา ต้องทำผลวิเคราะห์และผลออกแบบที่พึ่งพาค่านั้นให้stale จนคำนวณใหม่
- เก็บภาพR00และรายงานเดิม immutable; ห้ามทำให้ภาพconceptกลายเป็นapproved CAD ด้วยการเปลี่ยนชื่อไฟล์
- ไม่ใช้ผลหนึ่งอาคารซ้ำกับอีกอาคารหากเงื่อนไขแรง ช่องเปิด หรือจุดต่อไม่อยู่ในขอบเขตการรับรองเดียวกัน
